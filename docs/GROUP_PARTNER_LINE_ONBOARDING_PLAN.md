# 発信パートナーの専用LINE参加導線 調査と計画（2026-11-13）

対象: 2026-11-13 実装指示書 Phase 2（専用LINEの参加導線）。基準は `main` `e951ec7`。本書の作業では、Production設定、LINE実配信、リッチメニュー公開、DB変更を行っていない。

## 1. 現在の参加の流れ（コード確認）

1. 招待URL `/s/{slug}/join/{token}`（既存の `InvitationContent` を共用）で参加する。未ログインならログイン後に同じURLへ戻る。
2. 参加後は `/s/{slug}/home` へ移る（研修Serviceは `/training`）。
3. 初期質問が未回答なら `/s/{slug}/onboarding` へ移る。質問はServiceごとの設定で、`businessProfileEnabled` のServiceだけ事業者プロフィール（業種・事業名・商品など）を聞く。
4. 投稿パートナーの作成 `/s/{slug}/bunshins/new`。初期質問の回答からAIが案を出し、選ぶだけで作れる（手入力も可）。
5. 投稿パートナーホームでSNS設定をすると、今日の投稿案が届く。
6. 企業の企画への参加は、投稿パートナーホームの「グループの企画」から選ぶ（#1517）。

- 企業・Groupは招待URLから自動で決まる。本人の同意（Service参加同意・利用規約）は既存の参加手順で取得する。
- 一般参加者に会社名・事業内容を聞くのは、事業者プロフィールを有効にしたServiceだけ。ただし企業向けテンプレート（`ENTERPRISE_PROGRAM`）の初期質問には「会社や活動の中での役割」「どの商品や活動を知ってほしいか」など事業者向けの質問が6問あった。

## 2. 本書と同時に行う変更

- 企業向けテンプレートの初期質問を、一般の発信パートナー向けの3問（利用SNS、発信したいテーマ、使える時間）にする。会社・商品の情報は企業が登録した商品情報と企画から使い、参加者に重ねて入力させない。
- テンプレートはServiceを新しく作る時だけ使うため、既存Serviceの質問は変わらない。既存の企業Serviceで質問を減らす場合は、サービス設定の既存画面で変更する。

## 3. 専用LINE（企業向け設定）

- 既存の SHARED / DEDICATED / DISABLED と、専用LINEの資格情報・接続確認・リッチメニュー公開の手順をそのまま使う（DECISION_LOG 2026-11-07）。
- 専用LINEが停止中でも共通LINEへ自動で切り替えない動作は既存のまま。一般顧客向けの公式LINEには接続しない。
- 不足している接続情報だけを表示する案内は既存の管理画面にある。LINE Developersで準備する項目の簡潔な案内は、実際の企業アカウントでの接続確認と合わせて文言を見直す（非本番の専用LINEチャネルが必要）。

## 4. リッチメニュー（判断が必要）

- 現在のボタンは `LineRichMenuAction` の4種類（今日やること、投稿パートナー、お知らせ設定、アカウント）で、DBのenumとして保存している。
- 指示書の「今日の投稿・グループの企画・公式素材・マイページ」にするには、少なくとも「グループの企画」を開く操作の追加が必要で、enumへの値追加（migration）になる。AGENTS.mdの規則により、許可なくmigrationは作らない。
- 代替案（migrationなし）: 「今日やること」ボタンの移動先 `/s/{slug}/home` から、グループの企画と公式素材へ1タップで移れるようにする。#1517 で投稿パートナーホームに「グループの企画」導線を追加済み。
