# 運用設定管理画面 実装計画

## 1. 目的

日常運用で設定ファイルの編集、Vercelへの再登録、サーバー操作を必要としない管理画面を作る。

管理者は画面から次を行えるようにする。

- OpenAI APIキー、利用モデル、利用停止、接続確認
- LINE Login / Messaging API / LIFFの設定、接続確認、切替、停止
- LINEリッチメニューの作成、画像登録、確認、公開、切替、停止
- 通知時刻、休止時間、配信上限、緊急停止
- 設定変更履歴、接続エラー、現在利用中の設定の確認

## 2. 管理画面へ移す設定

### AI設定

- OpenAI APIキー
- BUNSHIN候補、発信方針、週間予定、今日の投稿案、内容作成、品質確認で使うモデル
- AI機能の全体停止
- 1回あたりのタイムアウト
- 月間利用上限と警告基準

APIキーは暗号化してDBへ保存し、保存後は末尾だけ表示する。SUPER_ADMINだけが登録・更新・無効化でき、OPERATORは接続確認と状態確認だけを行える。

### LINE設定

既存のLINE設定管理を継続利用し、運用設定画面から到達できるようにする。

- Login Channel ID / Secret
- Messaging Channel ID / Secret / Access Token
- LIFF ID
- 通知初期時刻、標準地域時間、休止時間
- 配信上限の警告・停止基準
- 全体停止

### LINEリッチメニュー

- 名前と説明
- メニュー画像
- 画面領域と押したときの動作
- 下書き、接続確認、公開、停止
- 利用中メニューの切替
- LINE側のリッチメニューIDと最終同期日時

初期版で用意する動作は次に限定する。

- 今日の投稿案を開く
- BUNSHIN一覧を開く
- 通知設定を開く
- アカウント画面を開く

任意URL入力は許可せず、アプリ内の許可済み遷移先から選択する。外部URL対応は別途Allowlistを設けた後に追加する。

## 3. 初回環境設定に残すもの

次は管理画面へ保存しない。アプリがDBや暗号化済み設定を読むための「土台」であり、日常的な変更対象ではない。

- `DATABASE_URL` / `DIRECT_URL`
- `APP_ENV` / `APP_URL`
- `SESSION_SECRET`
- `ENCRYPTION_KEY`
- `CRON_SECRET`
- Supabase公開接続情報
- `SUPABASE_SERVICE_ROLE_KEY`

`ENCRYPTION_KEY`を管理画面に置くと、暗号化済みAPIキーを守れないため、環境変数に残す。OpenAIとLINEの暗号鍵は、この親鍵からHKDFで用途別・環境別・版別に導出する。

## 4. 共通の安全要件

- DEVELOPMENT、STAGING、PRODUCTIONを完全分離する
- 環境ごとに使用中の設定は最大1件とする
- Production変更は確認画面と変更理由を必須にする
- 秘密値の平文取得APIを作らない
- API応答、ログ、監査履歴へ秘密値を出さない
- 設定は上書きせず版を追加し、切替履歴を残す
- 接続確認に成功した設定だけを使用中へ切り替えられるようにする
- SUPER_ADMINとOPERATORの操作範囲をサーバー側で検証する
- Provider障害、認証失敗、上限到達、設定不一致を分類して表示する
- PreviewからProduction設定を参照できないようにする

## 5. 実装順序

### PR 1: 設計と運用設定入口

- 本計画と設計判断を確定する
- 管理画面に「運用設定」の入口を追加する
- 現在の環境、AI、LINE、通知、退会処理の状態を一覧表示する

### PR 2: AI設定管理

- 環境別・版管理されたAI設定
- APIキーの暗号化保存と末尾マスク
- モデルと利用停止設定
- OpenAI接続確認
- 設定変更監査
- 既存のAI生成処理を使用中設定の解決へ接続
- 移行期間だけ`OPENAI_API_KEY`環境変数を代替経路として許可し、管理画面設定の有効化後に使用しない

### PR 3: LINEリッチメニューCore

- リッチメニュー定義、領域、動作、状態、LINE側ID、同期結果
- 環境・版・監査・冪等性
- 画像の安全な保存境界
- Messaging Provider Port

### PR 4: LINEリッチメニュー管理画面

- テンプレート選択
- 画像アップロード
- 表示内容の確認
- LINEへの登録、公開、切替、停止
- Providerエラー表示と再実行

### PR 5: 運用仕上げ

- 設定状態の一括確認
- 警告表示
- 操作手順と復旧手順
- 本番スマートフォン確認

## 6. 完了条件

- 日常的なOpenAIキー・モデル変更にファイル編集や再配備が不要
- LINEチャネル設定、通知停止、リッチメニュー切替を管理画面から行える
- 秘密値が画面、API応答、ログ、監査履歴へ再表示されない
- 設定変更者、対象環境、理由、日時、変更項目を確認できる
- 間違った設定を以前の版へ戻せる
- 接続失敗時に送信やAI生成を安全に停止できる
