# 深層パーソナル占い Phase 3 PR-2

`main` の `3be91892`（#1554）を基点に、鑑定前の動的ヒアリングと1日1回の既存タロット鑑定の間に、本人が確認できる相談内容を追加した。

## 利用者の操作

1. 「AIと相談を整理してから占う」で相談や質問に回答する。「ここまでで占う」を選ぶと、入力がある場合に確認画面が開く。
2. 入力は、説明した状況、気になっている理由、大切にしたいこと、望む状態、鑑定で知りたいことなどに分ける。未回答の項目を表示し、テーマから補った目的の候補は「未確認」と明示する。入力済みの内容は訂正・除外でき、候補は本人が採用した場合だけ使用する。
3. 「この内容で占う」を選ぶと、本人の入力・確認済みの内容を既存の一回限りの相談入力に渡す。個別化に同意している本人は、必要な項目だけを選んで継続保存できる。保存操作は任意。
4. 「設定」の「保存した相談内容」で、有効期限を確認し、項目の訂正・除外や一括削除ができる。本人プロフィールを保存し直した場合、同意撤回・退会した場合には、保存した相談内容も消去する。

## データと変更箇所

- `packages/capability-fortune/src/fortune-understanding.ts` に、入力量に応じて確認済み・未確認の候補・未回答を区別する処理を追加した。文意の書き換えや診断を生成せず、本人入力をそのまま扱う。整理のための追加AIリクエストは発生しない。
- `apps/web/app/s/[serviceSlug]/fortune-understanding.tsx` が確認画面と保存済みの設定画面を提供する。`/api/services/[serviceSlug]/fortune/understanding` で本人の閲覧・保存・削除を扱う。
- 既存 `fortune_participants` に確認済み項目、保存時刻、期限、競合検出用の版を追加した。入力元と本人確認状態は項目ごとに保持する。同意は既存のプロフィール同意を参照し、短い方の有効期限を適用する。既存の占い期限処理で物理削除する。
- 同時更新・削除後の再送は、プロフィールと保存内容の両方の版で検証する。管理画面には相談本文を渡さない。

## 検証と次の段階

構造化の区別、未確認候補の除外、元の相談入力の文字数上限、APIの入力検証、隔離DBの他人・他Service分離と同意撤回、競合、期限、スマートフォン幅の訂正と選択保存を自動検証する。

PR-3では、確認済みの今回の内容と実際のカード・正逆・標準解釈を統合し、構造化した鑑定と個別提案を出す。継続保存した内容の次回利用は後続の範囲とする。実AIを使う評価、本番反映・マイグレーション・通知は別途承認の対象。
