# HASSY 無償支援後の改善再判定 実装報告

## 調査と変更

無償支援完了後もBarrier Caseが `CONFIRMED` のまま残ることを確認し、既存行動ログから再観測するProjectionを追加した。

## 設計判断

- 支援完了後14有効日以上のみ判定する。
- システム障害日がある場合は判定しない。
- 同じCategoryの障壁が再推定されなければ `RESOLVED` とし、30日間の再検知抑止を設ける。
- 未改善はOEM支援候補Projectionへ渡す。

## 検証

- Database typecheck。
- 改善・システム障害の決定ルールテスト。2件成功。
- Web typecheckはローカル実行が長時間完了しなかったためCIで最終確認する。

## 未確認

本番の14日分の行動データによる `RESOLVED` 更新は未確認。
