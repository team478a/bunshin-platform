# AI・検索サービス 運用操作実装報告

## 実装内容

- OpenAI・Exa・Firecrawlの接続テスト
- 接続成功済み設定の有効化
- 使用中設定の緊急停止
- 同一環境・同一Providerの旧版自動停止
- 接続結果、有効化、停止理由の監査記録

## 安全策

- APIキーは接続テスト処理内だけで復号し、レスポンス・ログ・監査記録へ保存しない。
- 接続成功日時がなく、または直近エラーがある設定は有効化できない。
- 本番有効化には確認画面と理由入力が必要。
- 緊急停止はSUPER_ADMINとOPERATORが実行でき、理由を必須とする。
- 実行環境と設定環境が異なる設定は取得・操作できない。

## Provider確認方法

- OpenAIは指定モデルの取得APIで、鍵とモデル利用可否を確認する。
- Exaは結果1件の最小検索で確認する。
- Firecrawlはキャッシュ利用期間を指定した `example.com` の最小取得で確認する。

検索Providerの接続確認は少量の利用枠を消費する場合があるため、管理画面に明記した。
