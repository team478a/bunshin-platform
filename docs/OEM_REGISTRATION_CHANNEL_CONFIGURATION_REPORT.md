# OEM登録チャネル設定 実装報告

## 1. 調査結果

- `ServiceRegistrationPolicy`はサービスごとに`emailEnabled`と`lineEnabled`を保持している。
- 公開登録画面は保存値に応じてメールとLINEの入口を出し分け、両方の表示にも対応している。
- 企業向け無料テンプレートだけは、運用種別と登録チャネルが結び付けられ、保存値に関係なくLINE専用へ上書きされていた。
- 登録メールは共通Supabase認証メールであり、OEMごとの自動返信文面・送信元・メール配信資格情報は未実装である。

## 2. 今回の変更

- 企業向け無料テンプレートでも、運営者がメールのみ、LINEのみ、または両方を選べるようにした。
- 新規作成時と作成後のサービス管理画面の双方で選択可能にした。
- 無料運用の公開登録、招待コード停止、紹介元記録停止、毎日配信設定は維持した。
- ワタシワークス公式の既存値はLINEのみのまま維持される。運営者が変更した場合だけ設定が変わる。

## 3. 残るメール機能

次の独立した作業で、サービス単位の登録完了メールについて以下を追加する。

- 送信有無
- 件名と本文
- 送信者名、送信元、返信先
- テスト送信と送信元確認
- 登録・承認完了時の冪等な配信と失敗履歴
- 共通メール基盤を使う方式とOEM専用メール資格情報を使う方式の明示的な切替

認証用マジックリンクメールと登録完了後の案内メールは、セキュリティ上別の設定として扱う。
