# サービス別法務文書管理 実装報告

## ゴール

サービス運営者がサーバーやDBを操作せず、各サービスの利用規約とプライバシーポリシーを版管理して公開できるようにする。

## 実装

- `/groups/{groupId}/legal`にサービス専用の法務文書管理画面を追加
- 利用規約・プライバシーポリシーの下書きを作成
- 文書種別ごとに連番の版を自動採番
- 日本時間で利用開始日時を指定して公開
- 新しい版の公開時に、同じ種類の旧公開版を`RETIRED`へ変更
- 各版の同意済み人数を表示
- 作成・公開の理由と操作者をサービス設定監査ログへ保存

## 権限と分離

操作できるのは、対象サービスの管理者、同じ団体のOWNER/ADMIN、有効なSUPER_ADMIN/OPERATORだけである。

すべての取得・作成・公開で`workspaceId`と`groupId`を照合する。他サービスの文書IDを送信しても公開できない。

## 版管理

公開済み本文を直接上書きしない。参加者が同意した文書は旧版になっても残し、誰がどの版へ同意したかを追跡できる状態を維持する。
