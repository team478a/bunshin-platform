# 週次レポート実装記録

## 利用者向け

- サービスホームから「今週できたことを見る」を開ける。
- 投稿案の確認、コピー、投稿完了、休み、Daily Action素材、別案利用を週単位で表示する。
- ポイント獲得・利用と、その週に獲得したバッジを表示する。
- 数字の評価ではなく、次に行う一つの操作を日本語で案内する。
- 現在を含む過去12週を切り替えられる。

## 運営者向け

- サービス全体の参加者数、投稿、コピー、素材、休みを表示する。
- 投稿案を開いていない、閲覧後に止まった、複数回コピー後に投稿完了がない参加者を声かけ候補として表示する。
- 投稿本文、Daily Action本文、写真は運営レポートに表示しない。
- 参加者ごとの操作件数、ポイント獲得数、バッジ獲得数を表示する。

## LINE

- 週次レポート画面から公式LINE管理へ移動すると、安全な案内文を自動入力する。
- LINE本文には参加者別件数、投稿本文、本人素材を含めない。
- 既存の対象人数プレビューと送信確認を通して配信する。
- リンク先はログインが必要な本人向け週次レポート画面とする。

## 集計境界

- 本人画面はログイン利用者のIDで絞る。
- 運営画面はサービス管理権限を必須とし、そのサービスの有効な参加者だけを集計する。
- 日付は Asia/Tokyo の月曜日から日曜日までを一週間として扱う。
