# 月と星のオラクルの単発販売検証

対象 Service は `watashi-fortune`。検証環境で占い、AI、個別化、動的ヒアリング、深層鑑定を有効にする。規約、プライバシーポリシー、特定商取引法の表示を用意する。提供時期、返金の条件と申請先は、商品設定と公開文書で揃える。開始価格案は税込1,980円。運営者が商品設定に入力し、最終確認画面の内容を確認する。

1. 既存の決済設定に Stripe テストアカウントを接続する。署名付き Webhook に `checkout.session.completed`、`checkout.session.expired`、`payment_intent.payment_failed`、`charge.refunded` を設定する。
2. 年齢確認済みの参加者で、商品詳細と Stripe 最終確認画面の価格、回数、提供時期と返金条件を確認する。決済画面から戻って再開しても購入が増えないことを確認する。
3. テストカードの拒否と成功を確認する。購入画面の戻りリンクを先に開いても、入金イベントがなければ鑑定権限が付かないことを確認する。同じイベントを再送しても購入・鑑定が増えないことを確認する。
4. 個別化に同意し、ステラのヒアリングで相談内容を確認して深層鑑定を開始する。提供済みの購入、同じ鑑定の追加質問回数、鑑定履歴、AI使用量を確認する。
5. 別の参加者で先に無料占いを行い、同日に購入して深層鑑定へ進む。無料結果とカード・正逆・テーマ・Reading ID が同じことを確認する。深層鑑定を再送しても同日の提供は1回とする。
6. 生成失敗時は購入履歴で未提供であることを確認する。本人に相談内容を再確認して再試行してもらう。対応できない場合は公開済みの条件に沿って Stripe 側で権限のある担当者が返金する。Webhook 到達後に未提供分と追加質問が停止し、部分返金の累計額が購入履歴と一致することを確認する。
7. 決済の存在が不明な場合は管理画面の購入IDを Stripe の Checkout の client reference または PaymentIntent の metadata (purchase_id) と照合する。最初の Checkout が未確定の間は同じ購入から再開する。期限切れ・返金のイベントは Stripe から再送できる。購入状態を手動で入金済みに変更しない。

Stripe テストの証跡には対象環境、コードSHA、Checkout・イベント・購入ID、結果とAI原価の記録有無を残す。カード番号、相談本文、鑑定本文は転記しない。

本番へ進む前に、管理者が承認済みの表示・問い合わせ先と返金手順を確認し、コード・DB・本番の接続を検証する。初回の実請求と販売有効化は明示承認後に行う。

- [Stripe Checkout の提供処理](https://docs.stripe.com/checkout/fulfillment)
- [消費者庁の最終確認画面の案内](https://www.no-trouble.caa.go.jp/pdf/20240315ac01.pdf)

## 収益分析

占い管理の「占い収益分析」で対象月（日本時間）と決済環境を選ぶ。テスト購入は本番売上の集計から除く。広告費はチャネル別の実績を入力する。決済手数料は Stripe の取引明細で JPY の金額を確認し、購入IDで記録する。AI原価は既存の使用量台帳に記録された推定USDを参照する。円換算が必要な場合は当月の換算根拠を確認し、換算レートを入力する。

チャネルは Service の確認済み紹介、または LP の最初の訪問時に記録した UTM を利用する。計測できなかった注文は集計上「unknown」として扱う。自社の訪問計測では30日間のファーストパーティCookieを使い、送信時は UTM の source、medium、campaign の識別子に限定する。相談本文、心理情報、鑑定内容、広告用のクリックIDを保存したり広告事業者へ送信したりしない。公開前に自社計測の利用目的・Cookie を公開済みのプライバシーポリシーで確認する。

月次の限界利益は購入月の売上に、集計月末までに確認できた返金、手数料、AI原価を対応させる。返金欄には当月に観測した返金額を表示する。広告費・手数料・AI原価が空欄の場合は、取得後に採算を判断する。観測LTVは過去の購入実績を顧客単位で集計する。

## 商品仮説と販売実証

占い管理から3つの企画の名前、価格案、案内文、外部リンクを編集できる。関心受付を有効にすると利用者の「今後の企画」に表示される。利用者の関心を確認し、運営者が案内・外部窓口への紹介の進捗を保存する。利用者は関心登録を取り消せる。

発売前の企画は関心登録として扱う。申込、支払、予約、配送が必要になった場合の窓口は既存LP、ショップまたは提携先を使用する。計測のために相談内容や鑑定内容を転記しない。

最初に検証する仮説は「無料鑑定で引いたカードを使えることを伝えると、相談を整理したい参加者が税込1,980円で深層鑑定を購入する」。集客元と案内文の版、観測期間、提供原価と返金を記録する。販売1件は導線の成立確認に使う。改善の効果は期間や対象者の違いも考慮し、比較条件を残して追加検証する。
