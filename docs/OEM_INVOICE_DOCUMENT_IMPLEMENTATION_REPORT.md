# OEM月額請求書PDF 実装報告

## 1. 目的

確定MAUから作成したOEM月次請求について、運営団体がスマートフォンまたはPCから請求書PDFを保存できるようにする。外部請求書と内部請求台帳の二重管理を減らし、発行後の内容が変更されないことを優先する。

## 2. 実装内容

- 請求を「請求済み」にする時点で文書内容をJSON Snapshotとして固定
- 請求番号、対象期間、MAU、支払期限、請求元、請求先を表示
- 既存の請求総額を税込金額として扱い、10%内税を表示
- Noto Sans JPを使って日本語のA4 PDFをサーバーで生成
- システム管理者と対象団体のOWNER/ADMINだけが取得可能
- `ISSUED`または`PAID`の請求書だけを取得可能
- ダウンロードのたびに既存の請求監査へ履歴を保存
- private/no-store、nosniffを付けてブラウザーキャッシュを抑制

## 3. 不変性

請求書は発行時の請求元、請求先、税額、対象期間を`tenant_invoices.document_snapshot`へ保存する。団体名、住所、請求先や環境設定を後から変更しても発行済み文書は変化しない。再ダウンロードは同じSnapshotから生成する。

## 4. 請求元設定

本番環境では次のserver-only環境変数を設定する。

- `PLATFORM_BILLING_ISSUER_NAME`
- `PLATFORM_BILLING_ISSUER_POSTAL_CODE`
- `PLATFORM_BILLING_ISSUER_ADDRESS`
- `PLATFORM_BILLING_INVOICE_REGISTRATION_NUMBER`

名称と住所は未設定時に現在の運営元情報を使用する。郵便番号と適格請求書発行事業者の登録番号は確認済みの値がある場合だけ表示し、推測した番号は生成しない。

## 5. 金額の扱い

既存のStripe決済額と請求台帳の`amount_yen`は変更しない。`amount_yen`を税込総額として、消費税額を`floor(amount_yen * 10 / 110)`で計算し、税抜金額との差額が必ず総額と一致するようにする。

## 6. 操作方法

1. システム管理者が下書き請求を「請求済み」にする
2. 発行時点の請求書Snapshotが保存される
3. システム管理画面、または対象団体の利用状況画面でPDFを保存する
4. 再度必要な場合は同じボタンから再ダウンロードする
5. システム管理者は契約・請求の変更履歴でダウンロード日時を確認する

## 7. 対象外

- 電子帳簿保存法に対応した長期ファイル保管サービス
- 請求書への押印画像
- 軽減税率、複数税率、外貨
- 過去に発行済みでSnapshotがない請求書の自動補完
