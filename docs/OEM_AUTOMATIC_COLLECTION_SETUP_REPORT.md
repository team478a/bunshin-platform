# OEM月額料金 自動回収準備 実装報告

## 1. 目的

既存OEMへ無断で自動課金を適用せず、団体ごとの明示的な契約同意と初回Stripe支払いを経て、次回以降の自動回収に使う支払方法を安全に準備する。

## 2. 実装内容

- 自動回収は全契約で既定停止
- システム管理者が契約上の同意確認後に団体単位で有効化
- 有効化済み契約の初回Checkoutだけ`off_session`利用のための支払方法保存をStripeへ要求
- Checkout完了後、Stripe APIで成功済みPaymentIntentを再確認
- DBにはStripe Customer IDとPayment Method IDだけを保存し、カード番号やWebhook本文は保存しない
- 団体管理者画面に「未使用／最初の支払い待ち／準備済み」を表示
- 自動回収を無効化すると同意日時を解除する。保存済み参照は監査・再同意時の照合のため削除しない

## 3. 安全境界

- OEM権限、契約中、Stripe請求の既存条件を維持する
- 別Workspaceの支払方法を更新できない
- 自動回収が有効な契約だけ支払方法参照を更新する
- 支払成功、金額、通貨、Checkout Session、署名済みWebhookの既存照合後に保存する

## 4. 次のゴール

準備済み契約だけを対象に、発行済み請求を冪等な日次処理で回収する。失敗時は手動Checkoutを維持し、支払期限超過による利用停止は別の明示設定と猶予期間を設ける。
