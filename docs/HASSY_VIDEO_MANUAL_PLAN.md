# ハッシー 初心者向け動画マニュアル案

## 1. このマニュアルの目的

この動画シリーズは、ハッシーを初めて使う事業者・店舗・個人事業主が、登録後に迷わず「今日の集客」を一つ進められるようにするためのものです。

ハッシーは、業種、事業内容、発信目的、対象者をもとに、SNS発信を続けるためのテーマや行動を提案する伴走サービスです。利用者が毎回ゼロから投稿内容を考える負担を減らし、次の順番で実行できるようにします。

```text
事業情報を登録
  ↓
投稿パートナーを準備
  ↓
LINEまたはサービスホームで「今日やること」を確認
  ↓
SNSへ投稿、または今日の集客行動を実行
  ↓
結果を記録
  ↓
次の提案と振り返りに活かす
```

この文書はハッシー専用です。千ノ国メディア、マナベル、副業版、その他のサービスの画面・登録手順・機能は扱いません。

## 2. 初心者に最初に伝えること

### 2.1 ハッシーで解決すること

- 今日、何をSNSで発信すればよいか分からない
- 商品やサービスの紹介が毎回同じになる
- お客様からよく聞かれる質問を発信に活かしたい
- 忙しくても毎日少しずつ集客を進めたい
- 投稿した後の反応を記録し、次の発信に活かしたい

### 2.2 ハッシーがすること・しないこと

| ハッシーがすること | ハッシーがしないこと |
| --- | --- |
| 事業情報に合う発信テーマや今日の行動を提案する | 利用者のSNSへ無断で投稿する |
| LINEで案内を届ける | 投稿の成果や売上を保証する |
| 投稿文をコピーして使えるようにする | 事実確認なしに商品情報を公開する |
| 実施結果やお客様の反応を記録する | 利用者の代わりに最終判断をする |

最終的な内容確認とSNSへの投稿は利用者本人が行います。

動画は一本の長い説明ではなく、スマートフォンで見やすい短編8本に分けます。トップ動画を見たあと、必要な動画だけ見直せる構成にします。

| 2 | 初めての登録 | ログインから事業情報・通知設定まで進める | 4分 |
| 3 | 投稿パートナーとは？ | 投稿パートナーの役割と設定内容を理解する | 2分 |

## 4. 各動画の台本・絵コンテ

### 動画1：ハッシーとは？

**冒頭のナレーション**

> ハッシーは、あなたの事業に合ったSNS発信を、毎日ひとつずつ進めるためのサービスです。難しい設定や、毎回ゼロから考える作業を減らします。

**画面の順番**

1. ハッシーのサービス名を表示
2. 「事業情報を登録」から「今日やること」までの流れを図で表示
3. 店舗、会社、個人事業の利用例を3つ表示
4. 「投稿の最終確認と公開は自分で行う」と表示
5. 「次は初めての登録へ」と案内

**利用例**

- 飲食店：今日のお店のこだわりを紹介する
- 美容・専門サービス：よくある質問に答える
- 小さな会社・個人事業：商品やサービスの使い方を紹介する

### 動画2：初めての登録

**画面の操作**

1. `/s/hassy` を開く
2. 「ログインして続ける」を押す
3. ハッシーへの参加と必要な同意を確認する
4. 業種を選ぶ
5. 事業名、地域、商品・サービスを入力する
6. 発信目的と対象者を入力する
7. 利用するSNSと通知時刻を確認する
8. LINE通知を開始する

**ナレーションの要点**

> ここで入力した内容が、ハッシーの提案の土台になります。立派な文章を書く必要はありません。今の事業を、短い言葉で入力してください。

**完了条件**

- サービスホームが表示される
- 「投稿パートナーを作る・見る」が表示される
- LINE通知の設定が有効になっている

### 動画3：投稿パートナーとは？

**説明する内容**

投稿パートナーは、利用者の事業、目的、対象者、文章の雰囲気をもとに、投稿や今日の行動を一緒に考えるための設定です。人間の担当者やSNSアカウントそのものではありません。

**画面の操作**

1. 「投稿パートナーを作る・見る」を押す
2. 名前と目的を確認する
3. 対象者と発信テーマを確認する
4. 内容を修正する場合は保存する

**注意表示**

> 投稿パートナーを作り直すときも、別のサービスの情報を入力しないでください。ハッシーの事業情報だけを使います。

### 動画4：毎日の「今日やること」

**画面の操作**

1. LINEに届いたハッシーの案内を開く
2. サービスホームで「今日やることを見る」を押す
3. 今日の提案の目的と内容を読む
4. 「採用する」または「今回は使わない」を選ぶ
5. 今日実行する一つの行動を確認する

**ナレーションの要点**

> すべてを一度にやる必要はありません。まずは、今日表示された一つの行動だけを進めます。

提案がまだない場合は、準備中または通知設定が未完了の可能性があります。画面を開き直し、解決しなければ運営者へ連絡します。

### 動画5：SNSへ投稿する

**画面の操作**

1. 投稿内容を最後まで読む
2. 必要なら自分の言葉に修正する
3. 「投稿文をコピー」を押す
4. InstagramなどのSNSを開く
5. 投稿文を貼り付け、写真・表現・リンクを確認する
6. SNSの投稿ボタンを押す

**必ず表示する注意**

> コピーしただけでは投稿完了ではありません。SNSの画面で内容を確認してから、自分で投稿してください。

ハッシーからSNSへの自動投稿は行いません。

### 動画6：投稿後に記録する

**画面の操作**

1. ハッシーへ戻る
2. 「投稿しました」を押す、または実行結果を選ぶ
3. 「できた」「一部できた」「できなかった」から選ぶ
4. 必要に応じて、お客様の反応を短く記録する

**説明する内容**

- 記録は次の提案を調整するために使う
- 名前や個人情報を入力する必要はない
- 実際に投稿・実行した後に記録する

### 動画7：進み具合を確認する

**画面の操作**

1. サービスホームの「今週の進み具合」を見る
2. 「今週できたことを見る」を開く
3. 90日計画が表示される場合は「90日計画を見る」を開く
4. 現在地と次の行動を確認する

**説明する内容**

> ハッシーは、一度の投稿だけでなく、無理なく続けることを重視します。できなかった日があっても、次の行動を確認して再開できます。

90日計画やSNS集客の準備画面は、ハッシーのサービス設定で有効な場合だけ収録します。

### 動画8：通知停止と困ったとき

**通知停止・再開**

1. 投稿パートナーの設定を開く
2. LINE配信設定を開く
3. 通知の停止または再開を選ぶ
4. 通知時刻を確認する

**困ったときの案内**

| 状況 | 最初に確認すること |
| --- | --- |
| LINEが届かない | LINEの友だち状態、通知同意、通知時刻 |
| 今日の提案がない | 準備中でないか、サービスホームを再表示 |
| ログインできない | ハッシーの案内から最新のログインリンクを開く |
| 別の画面が出る | URLが`/s/hassy`であることを確認する |
| コピーできない | 文章を長押しし、「すべて選択」→「コピー」 |

最後に、解決しない場合は「押したボタン」「表示された言葉」「発生日時」の3点と画面の写真を運営者へ送るよう案内します。

## 5. 動画制作ルール

- スマートフォンの縦画面、9:16で収録する
- 1画面につき一つの操作だけ説明する
- タップ位置を丸印または拡大で強調する
- 音声と字幕を同じ内容にする
- 画面上部または冒頭に必ず「ハッシー」と表示する
- 他サービスのロゴ、URL、文言、通知画面を収録しない
- 実在のメールアドレス、LINE ID、顧客情報、APIキーを表示しない
- 画面の読み込み中は編集で飛ばさず、「準備中」と説明する
- 1本の長さは5分以内にする

## 6. 収録前に確認する項目

以下は、実際のハッシーの設定と画面を確認してから台本を確定します。

- 公開サービス名とロゴ
- 初回登録で表示される質問項目
- 業種の選択肢
- LINE通知の初期時刻と変更可否
- 投稿するSNSの選択肢
- 「発信アイデア」か「完成した投稿文」か
- 90日計画、SNS集客診断、週次レポートの有効状態
- 実際のボタン名とエラー表示
- ハッシー専用の問い合わせ先

## 7. 完成判定

次の条件を満たしたら、初心者向け動画マニュアルの第1版を公開できます。

1. 未登録のテストアカウントで、動画2の最初から最後まで再現できる
2. 動画4のLINE案内から「今日やること」へ進める
3. 動画5の手順でSNS投稿まで完了できる
4. 投稿後の記録が週次の進み具合へ反映される
5. 通知停止後に通知が送られないことを確認できる
6. すべての画面にハッシーのサービス名が表示され、他サービスと混同しない

## 8. 次の作業

1. ハッシー専用のテストアカウントを用意する
2. 上記8本の画面を実機で収録する
3. 収録後、実際の画面と台本の差分を確認する
4. 字幕付き動画を作成する
5. ハッシーのサービスホームまたはヘルプから「動画マニュアル」へリンクする

この段階では動画ファイルや本番画面へのリンクはまだ作成しません。実機収録で確認した表示を正本としてから公開します。
