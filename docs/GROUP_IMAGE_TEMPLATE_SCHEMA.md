# グループ限定SNS画像テンプレート仕様

## 1. 目的と範囲

グループ限定SNS画像生成で使用する、管理されたレイアウトの正本を定める。出力は縦長`1080 × 1350px`、テンプレート版は`1`とする。

本仕様はレイアウトSchema、入力検証、文字・画像領域、セーフエリア、Satori / resvg / Sharpによる決定的描画までを対象とする。外部AIによる素材生成、非公開Storage、利用者UIは後続PRで実装する。

## 2. 共通ルール

- Canvasは`1080 × 1350px`で固定する。
- 基本セーフエリアは上・右・下・左を72px以上空けた`x=72, y=72, width=936, height=1206`とする。
- AIや利用者から任意のHTML、CSS、SVG、座標、フォントサイズを受け取らない。
- 入力は`SocialImageLayout`だけとし、テンプレートKeyに対応する管理Schemaで検証する。
- 見出し・本文の各行・CTAに改行、制御文字、双方向テキスト上書き文字を許可しない。
- 文字数はUTF-16の長さではなくUnicode code point単位で数える。
- 上限を超えた場合は文字を極端に縮小せず、`VALIDATION_ERROR`として文章短縮工程へ戻す。
- 最小フォントサイズを下回る自動縮小は禁止する。
- 色は`#RRGGBB`だけを許可し、大文字へ正規化する。
- テンプレート定義、配置、文字規則はApplication層の`social-image-templates.ts`を実装上の正本とする。

## 3. テンプレート

| Key                 | 用途             | 素材     | 見出し                | 本文                   | CTA              |
| ------------------- | ---------------- | -------- | --------------------- | ---------------------- | ---------------- |
| `PERSON_HEADLINE`   | 人物と強い見出し | 前景人物 | 1〜2行、1行20文字まで | 1〜3行、1行28文字まで  | 任意、30文字まで |
| `PROBLEM_CHECKLIST` | 悩み・確認項目   | なし     | 1〜2行、1行22文字まで | 3〜5行、1行32文字まで  | 必須、30文字まで |
| `THREE_POINTS`      | 3つの要点        | なし     | 1〜2行、1行22文字まで | 3行固定、1行34文字まで | 任意、30文字まで |
| `EMPATHY_QUOTE`     | 共感・引用風     | 背景     | 1〜3行、1行20文字まで | 1〜3行、1行28文字まで  | 任意、28文字まで |
| `CTA`               | 行動の後押し     | 前景画像 | 1〜2行、1行20文字まで | 1〜3行、1行30文字まで  | 必須、26文字まで |

座標、通常フォントサイズ、最小フォントサイズはコードの版管理された定義を参照する。後から変更する場合は既存Versionを上書きせず、新しいテンプレートVersionとして追加する。

## 4. 素材配置

- `NONE`: AI素材を使用しない。
- `FOREGROUND`: 定義済み画像領域へ人物または主要被写体を配置する。
- `BACKGROUND`: Canvas全面へ背景として配置し、文字の可読性を確保する処理を後続レンダラーで行う。
- 切り抜きやトリミングでは顔・主要被写体を保護する。検出結果が不十分な場合は勝手に重要部分を切らず、生成を失敗として扱う。
- 素材領域と文字領域はテンプレートごとに固定し、Providerの出力から座標を受け取らない。

## 5. レンダラーへの引き渡し

レンダラーは`buildSocialImageCompositionPlan`の結果だけを受け取る。Composition Planには正規化済みLayout、テンプレートKey、テンプレートVersion、固定領域と文字規則が含まれる。

レンダラーは次を守る。

- 同梱したNoto Sans CJK JP Regular / Boldだけを使用し、OSフォントを読み込まない。
- 外部入力をHTMLとして解釈しない。
- 素材はBufferだけを受け取り、外部URLを取得しない。
- JPEG、PNG、WebPだけを許可し、15MB、1辺8192pxを上限とする。
- SatoriでSVGを構成し、resvgでPNG化し、Sharpでメタデータを引き継がず再出力する。
- 完成画像は1080×1350px、サムネイルは324×405pxとする。
- 同じ入力と同じ依存Versionから同一byte列を生成し、SHA-256を内容Hashとする。
- 元素材、完成画像、サムネイルを分離する。保存はI3-Cで実装する。
- 完成物を公開URLとして保存しない。
- 文字あふれを検出した場合、最小サイズより縮めず安全な失敗にする。

## 6. 変更管理

テンプレートKeyの意味、Version 1の座標や上限は生成済み画像の再現性に関わるため上書きしない。変更時は新Versionを追加し、生成Requestへ使用VersionをSnapshot保存できるようPersistenceを拡張する。
