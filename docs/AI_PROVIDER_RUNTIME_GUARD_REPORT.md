# AI・検索サービス 実行時ガード実装報告

## 目的

管理画面の設定を生成処理へ接続する前に、安全でない設定や予算超過を共通境界で拒否する。

## 実装内容

- 実行環境・Providerに一致するACTIVE設定だけを取得
- 全体停止、未確認、直近エラー、APIキー未登録を拒否
- UTC日次・月次のAI利用原価を集計
- 日次または月次上限到達時に実行を拒否
- 暗号化APIキーを復号せずApplication境界まで渡す

## 現時点の接続範囲

本PRでは既存生成処理の環境変数参照を置き換えない。Resolverのレビュー後、OpenAI生成処理と検索Jobを個別に接続する。

Exa・Firecrawlは検索利用量をAI利用イベントへ記録する処理がまだないため、検索Provider接続時に利用量記録も同時に追加する。
