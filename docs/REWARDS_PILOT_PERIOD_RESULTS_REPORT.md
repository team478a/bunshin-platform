# ポイント・バッジ試験期間集計 実装報告

## 問題

試験運用の結果は直近28日かつ現在利用中の参加者だけで集計していた。このため、設定した終了日時を過ぎると参加者が集計対象から外れ、4週間の結果を確認できなくなっていた。

## 変更

- サービスに設定した試験開始日時と終了日時を集計期間として使用する。
- 期間が終了した後は終了日時で集計を固定する。
- 現在は期限切れでも、試験期間中に利用対象だった参加者を母数へ残す。
- 投稿した人、3日以上続けた人、ポイントを使った人、投稿数、付与量、利用量、確認候補を同じ期間で集計する。
- 試験前、実施中、終了後、期間未設定を画面上で区別する。
- 現在利用できる人数と、結果集計の参加者数を分離する。

## 運用

システム管理者はポイント・バッジのサービス許可に開始日時と終了日時を設定する。終了後もサービス管理の「ポイントとバッジ」から同じ期間の結果を確認できる。

現在の設定行を次回試験用に変更すると表示対象も新しい期間へ切り替わる。過去の複数試験を並べて保存する機能は今回の範囲に含めない。
