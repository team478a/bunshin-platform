2. 本サービスを利用する方（以下「利用者」といいます。）は、本規約に同意したうえで本サービスを利用します。
3. 本規約のほか、運営者が本サービス内またはLINE等で案内するルールも、本規約の一部を構成します。本規約と個別の案内が異なる場合は、個別の案内を優先します。

1. 本サービスは、利用者が登録した業種、商品・サービス、対象顧客および発信目的等に基づき、SNS等で使用できる投稿案その他の情報を提供します。
2. 無料運用では、原則として1日1件の完成した投稿文章をLINEで配信します。配信頻度、内容および提供方法は、運営上の都合により変更することがあります。

4. 本サービスが提供する内容は情報発信を補助するための提案です。利用者に代わってSNSへ自動投稿するものではありません。

## 第3条（登録）

1. 本サービスは、事業または活動に関する情報発信を行う企業、店舗、個人事業主その他運営者が認めた方を対象とします。
2. 利用希望者は、運営者が指定するLINEその他の方法で、正確な情報を登録しなければなりません。
3. 登録内容に変更があった場合、利用者は速やかに登録情報を更新し、または運営者へ連絡します。
4. 運営者は、登録情報に虚偽がある場合、過去に利用停止を受けた場合、その他利用を適当でないと合理的に判断した場合、登録または利用を認めないことがあります。

## 第4条（アカウントとLINE連携）

1. 利用者は、自身のアカウントおよびLINE連携を適切に管理し、第三者に利用させてはなりません。
2. 利用者の管理不足または第三者による利用によって生じた損害について、運営者に故意または重大な過失がある場合を除き、運営者は責任を負いません。
3. LINEの利用には、LINEヤフー株式会社が定める利用条件も適用されます。

## 第5条（投稿内容の確認と利用者の責任）

1. 利用者は、本サービスが作成または提案した内容を公開する前に、事実関係、表現、権利関係、必要な表示および利用するSNSの規約を自身で確認します。
2. 利用者は、投稿内容および投稿によって生じる結果について責任を負います。
3. 医療、法律、税務、金融その他専門的判断を要する事項について、本サービスの出力は専門家の助言に代わるものではありません。
4. 運営者は、閲覧数、反応、集客、予約、来店、売上その他の成果を保証しません。

## 第6条（入力情報および素材）

1. 利用者は、文章、写真、画像、動画、音声、URL、商品情報その他本サービスへ入力または提供する情報について、必要な権利および許可を有していることを確認します。
2. 利用者は、第三者の個人情報、著作物、肖像、商標その他の権利を含む素材を、権利者の許可なく入力または利用してはなりません。
3. 運営者は、本サービスの提供、安全管理および品質改善に必要な範囲で、利用者が入力した情報および素材を取り扱います。

## 第7条（知的財産権）

1. 本サービス、画面、仕組み、ロゴ、文章テンプレートその他運営者または正当な権利者が保有する知的財産権は、運営者または当該権利者に帰属します。
2. 利用者が本サービスへ入力した情報および素材の権利は、利用者または正当な権利者に留保されます。
3. 利用者は、本サービスから提供された投稿案等を、自身または所属する事業・活動の情報発信に利用できます。ただし、第三者の権利を侵害する内容、法令に違反する内容または本規約に反する方法では利用できません。
4. AI等により生成された内容について、運営者は独占性、第三者の権利を侵害しないこと、または知的財産権が成立することを保証しません。

## 第8条（ポイントおよびバッジ）

1. ポイントおよびバッジは、本サービス内の活動を支援するための機能であり、現金、電子マネーその他の財産的価値を有するものではありません。
2. ポイントおよびバッジを第三者へ譲渡、貸与、売買または換金することはできません。
3. 付与条件、利用条件、有効期限および交換対象は、本サービス内の表示または運営者の案内によります。
4. 不正取得、誤付与、システム障害その他合理的な理由がある場合、運営者はポイントまたはバッジを訂正、取消しまたは停止できます。
5. 利用資格の終了または退会により、未使用のポイントおよびバッジは失効します。ただし、運営者が別途定める場合を除きます。

## 第9条（禁止事項）

利用者は、次の行為をしてはなりません。

1. 法令または公序良俗に反する行為
2. 虚偽、誤認、差別、誹謗中傷、嫌がらせまたは権利侵害につながる内容を作成・公開する行為
3. 第三者の個人情報または秘密情報を不正に入力、取得、利用または公開する行為
4. 本人の許可なく第三者になりすます行為

8. その他、運営者が不適切と合理的に判断する行為

## 2. 取得する情報

当社は、本サービスの提供に必要な範囲で、次の情報を取得します。

1. 氏名、表示名、メールアドレスその他のアカウント情報
2. LINEユーザー識別子、LINE表示名、友だち追加・連携・通知同意・配信に関する情報
3. 業種、活動名、会社・店舗名、活動地域、発信目的、対象顧客、商品・サービス、SNSその他のプロフィール情報
4. 利用者が入力または提供する文章、写真、画像、動画、音声、URL、資料および問い合わせ内容
5. 投稿案、生成指示、採用・不採用、コピー、保存、投稿完了、感想、問い合わせ・予約・来店・購入等の自己申告その他の利用履歴

## 3. 利用目的

当社は、取得した情報を次の目的で利用します。

1. 本人確認、利用資格の確認、アカウント管理および不正利用防止
2. 利用者の事業に合った投稿案その他のコンテンツの作成
3. LINEその他の方法による投稿案、重要なお知らせおよび利用案内の配信
4. ポイント、バッジ、継続状況および特典の記録・表示・管理
5. 投稿後の反応および利用状況の集計、問い合わせ対応、障害対応およびサポート
6. 本サービスの安全管理、品質改善、機能改善および利用状況の統計分析
7. 規約違反への対応、権利保護および法令上必要な対応
8. 上記の目的に付随する目的

品質改善や統計分析を行う場合、当社は必要に応じて個人を直接識別しない形に集計または加工します。

1. 本サービスは、投稿案等の生成、認証、データ保管、配信その他の機能のため、AIサービス、クラウドサービス、LINEその他の外部サービスを利用します。

3. 当社は、委託先の選定、契約、アクセス制御その他必要かつ適切な監督を行います。
4. 外部サービス事業者が外国で情報を取り扱う場合、当社は適用法令に従い、当該国の制度等を確認し、必要な情報提供、同意取得または安全管理措置を行います。
5. 利用者は、機密情報や第三者の個人情報を入力する前に、その入力が必要か、必要な許可を得ているかを確認してください。

## 5. 第三者提供

当社は、次の場合を除き、本人の同意なく個人データを第三者へ提供しません。

1. 法令に基づく場合
2. 人の生命、身体または財産の保護に必要で、本人の同意を得ることが困難な場合
3. 公衆衛生の向上または児童の健全な育成に特に必要で、本人の同意を得ることが困難な場合
4. 国または地方公共団体等の法令上の事務への協力が必要で、同意により当該事務へ支障が生じるおそれがある場合
5. その他、個人情報保護法が認める場合

業務委託、事業承継および法令上の共同利用は、個人情報保護法上の第三者提供に該当しない場合があります。

## 7. 安全管理措置

当社は、個人データへの不正アクセス、漏えい、滅失または毀損を防止するため、次の安全管理措置を講じます。

1. 個人情報の取扱方針および責任体制の整備

3. 権限管理、認証、アクセス制御および操作記録
4. 通信の保護、秘密情報の分離管理、バックアップおよび脆弱性対応
5. 委託先の選定および監督
