# ユーザー停止・問い合わせ対応管理

## ゴール

ログイン障害、不正利用、問い合わせ対応で、管理者がサーバーやDBを直接操作しない状態にする。

## 管理画面でできること

- ユーザー利用停止・再開
- 停止・再開理由と操作履歴の確認
- 問い合わせ記録の作成
- 未対応・対応中・解決済みを横断表示する対応受信箱
- 優先度、対応状態、担当管理者の変更
- 対応メモの追記と履歴確認

## 安全策

- 利用停止・再開は最高管理者だけが実施する
- 管理者アカウントはユーザー詳細から停止しない
- 利用停止時にLINE通知を無効化する
- 停止前のログイン状態が残っていても利用を継続させず、同じ認証情報から別ユーザーを作らない
- 再開時に通知を自動再開しない
- 対応メモは編集・削除せず、誰がいつ記録したか残す
- パスワード、APIキー、Token、投稿本文を対応メモへ保存しない

## 後続候補

- 障害、配信失敗、費用超過を集約する通知センター
- CSV出力と定期運用レポート
