# 参加質問の選択式UI

## 目的

スマートフォン利用者が長文を入力しなくても、投稿提案に必要な初期回答を完了できるようにする。

## 実装

- 標準の副業・企業向け質問と千ノ国メディア向け質問を、大きな単一選択ボタンで表示する。
- 各質問に「ほかの回答」導線を用意し、必要な場合だけ自由入力欄を表示する。
- 運営者独自の質問には自由入力を残す。
- 回答は既存と同じ質問・回答の文字列スナップショットとして保存し、後続の投稿パートナー提案へ渡す。

## 境界

- 自動投稿は行わない。
- データベース変更はない。
- 保存先、参加者本人、サービス境界は既存の参加回答処理を継続利用する。
