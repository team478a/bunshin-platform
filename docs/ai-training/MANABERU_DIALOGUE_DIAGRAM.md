# マナベルスタイルの会話＋図解

## 制作画面

1. 開発環境で、ワークスペースの「操作教材」から編集する教材を開く。
2. 章に相当する教材の中で対象の手順を選ぶ。その手順の「会話＋図解」に、二人の声と表示名、台詞、読み、台詞後の間を入力する。
3. 図の項目と、矢印を動かす台詞、読みの中の合図を指定する。台詞に全角の「｜」を入れると、合図に合わせて後半の字幕に切り替わる。
4. 「二人の連続試聴を作る」を押す。二人の音声を聞き、「縦型MP4を開く」で同じ素材から作った動画を再生できる。
5. 一言だけ直して「変更を反映して連続試聴を作る」を押す。生成と再利用の件数は試聴の下に表示される。

「交通費申請の例を入れる」で、検証用の5台詞と3つの図の項目を入力できる。検証用台本は合成データで、実際の領収書や社内システムは使用しない。

## 実装の境界

- カリキュラム、教材、章に相当する教材のまとまり、手順の紐付け、図の見た目と強調はマナベルが管理する。既存の教材一覧、詳細画面、教材の所有者認可を再利用する。
- 共通エンジンに台詞、配役ごとの声、字幕、VOICEVOXのモーラ時刻、保持する前回の素材受領記録を渡す。エンジン側で同期、再利用判定、FFmpegによる連続試聴・MP4の結合を行う。
- 操作手順ごとの台本と最新の動画を、認可済み利用者の保存領域で管理する。原画は初回にローカルで描画して登録し、同じワークスペース・利用者・配役では、別の手順でも登録済みPNGを使う。試聴や動画の変更で原画を再生成しない。
- 初期検証はワークスペースの開発用操作教材管理画面と、単一ホストの非公開ファイル領域を使う。編集画面はVOICEVOXの接続先と保存場所の両方を設定した場合に表示する。複数ホストでの実行、学習者向け公開と配信は別途接続が必要。

## 実行環境

| 設定                                                     | 用途                                                                        |
| -------------------------------------------------------- | --------------------------------------------------------------------------- |
| `MANABERU_DIALOGUE_MEDIA_DIR`                            | Webの公開ディレクトリとは別の、書き込み可能な専用絶対パス                   |
| `MANABERU_DIALOGUE_VOICEVOX_URL`                         | VOICEVOXのHTTP APIオリジン。末尾スラッシュ以外のパスを省く                  |
| `MANABERU_DIALOGUE_FFMPEG` / `MANABERU_DIALOGUE_FFPROBE` | 任意。未指定ならPATHから実行する。FFmpegはlibx264とlibassを含むビルドが必要 |
| `MANABERU_DIALOGUE_VOICEVOX_BRAND`                       | 任意。Nemoモデルの場合は `VOICEVOX Nemo` を設定し、動画内に表記する         |
| `MANABERU_DIALOGUE_FONT`                                 | 任意。Linuxは既定で Noto Sans CJK、Windowsは游ゴシックのフォントパスを使う  |

## 交通費申請の検証結果

[完成MP4（22.58秒）](media/manaberu-travel-expense-dialogue.mp4?raw=1)

VOICEVOX CORE 0.17.1 と Nemo の n0.vvm で、先輩は女声1、新人は男声1を使った。制作画面で連続試聴を再生し、3本の矢印をモーラ時刻に同期した。3番目の台詞を「検索結果を確認してから、申請窓口を選びます。」に直して、同じ画面から再生成した。

| 確認項目   | 結果                                                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 再生成     | 3番目の台詞のWAVと映像カットを各1件                                                                                            |
| 再利用     | 残り4台詞のWAVと映像カットは各4件。前後のSHA-256が一致。両役の原画も同じSHA-256                                                |
| 発話同期   | 2本目の矢印と「申請窓口を選びます。」の字幕切り替えが9.826秒から10.668秒へ移動。完成動画のフレームでも矢印の表示を確認         |
| 完成動画   | 制作画面を開き直して再生。720×1280、H.264、既定の日本語AACステレオ。全5台詞を復号し、先輩は左、新人は右が約14 dB強いことを確認 |
| 音声の表記 | 動画内に「VOICEVOX Nemo」を表示。[VOICEVOX Nemo利用規約](https://voicevox.hiroshiba.jp/nemo/term/)                             |

上の動画と素材比較は、実際の編集コンポーネントとAPIルートを起動し、認証・教材参照を検証用データにしたローカルのブラウザ試験で取得した。音声合成、WAV、映像カット、モーラ時刻、FFmpeg出力は実処理。Next.jsの既存教材画面への接続は開発用DBとテスト利用者で確認した。
