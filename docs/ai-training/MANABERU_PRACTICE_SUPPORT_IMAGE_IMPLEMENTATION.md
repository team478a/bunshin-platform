# マナベルスタイル：実践途中の画像相談

## 対象

進行中課題の相談に、本人が選ぶ静止画像を1枚添付できるようにする。相談は支援履歴であり、課題の評価・合格・達成には変換しない。課題の候補、作業記録、評価基準、Assignmentは変更しない。

## 実装

- スマートフォンを含む相談画面に画像選択、プレビュー、削除・差し替えを追加。クライアントのファイル選択は3MBまで。
- サーバーでJPEG/PNG/WebPを検査し、静止画・最大24MP・最大3MBに制限。EXIF等を除去して1600px以下のJPEGへ再符号化し、保存時512KB以下とする。
- 画像は支援リクエストイベント・Workspace・Service Group・Enrollment・Membership/User・Assignmentの複合所有関係に結び付け、DB内で保存する。既存のアクセス認可を通した本人だけが取得できる。第三者公開URLや外部Object Storageは追加しない。
- AI送信時に保存済みSHA-256と同一版を照合する。許可モデルのLearning Support入力だけにJPEGを低詳細度で付ける。画像内テキストは非信頼データとして扱い、見えない箇所の推測や公開・リンク動作・独力更新を成功判定しない。
- 既存のAI Admission、回数・費用予約、入力サイズ上限、利用量記録を再利用する。設定上限を超えた場合はAI送信前に失敗し、成功扱いしない。画像料金の独自推定や無料枠は追加しない。
- 画像メタデータ・本体を個人データ出力に含め、退会・学習データ削除・保持期限処理で消去する。親イベント、Assignment、Enrollment等の削除にもCascadeする。

## 確認と制限

合成テストは正規化、入力制約、画像モデル制約、イベント保存と本人取得、親イベント削除を確認する。実AIを使った画像相談、実ユーザーの効果、LINEからの再開、本番DBへのMigration適用は別確認であり、この変更だけでは確認済みにならない。本番反映・実AI実行・実送信・Pilot開始は行わない。

## 運用上の注意

既存 `PERSONAL_LEARNING_LESSON_ADMISSION.maxRequestBytes` が画像を含む要求より小さい環境では、画像付き相談は安全に失敗する。利用開始前に設定された上限を確認する。画像のAI費用はプロバイダ利用量の実測と既存料金表が示す範囲だけを計上し、料金不明を0円と扱わない。
