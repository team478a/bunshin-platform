# マナベルスタイル PR-4 開発環境での操作教材

[設計判断](../adr/MANABERU_BROWSER_INTEGRATION_PR4.md)

1. 使い捨て PostgreSQL に migration を適用する。
2. Web とブラウザワーカーの `APP_ENV` を `development` に設定する。Web で既存の個別学習を有効にし、ワーカーの `BROWSER_FIXTURE_DATABASE_URL` に同じ DB の接続先を指定する。
3. 管理画面の Program 機能設定で、停止中の `DYNAMIC_V1` 研修の「操作教材（開発環境）」と「本人との対話」を有効にする。既存手順で Program を開始し、開発用の内部参加者に既存の受講枠と同意を用意する。
4. 個別学習で「練習用メモをプレビューしたい」と入力し、使用端末を選んで保存する。「画像付き操作教材を確認する」から準備状況を開く。
5. `pnpm --filter @bunshin/browser-worker start once` で生成する。常駐する場合は既存コマンド `serve` を使う。教材が準備できたら、操作前後の画像、拡大、実践課題を確認する。LINE 学習が有効な場合は、準備済み教材へのリンクを既存の対話返信から開ける。

PC とスマートフォンの教材は各 Program で共有する。「両方」を選んだ場合は PC 版を案内する。既存の教材と画像を再利用するため、同じ端末向けの教材を準備済みの Program では保存時に生成ジョブを作らない。

生成時のブラウザ操作と画像加工は Playwright 1.65.1（Apache-2.0）と Sharp 0.35.4（Apache-2.0）を引き継ぐ。この経路の原価は AI 呼び出し 0 回、AI 原価 0 円。既存の会話に使う AI 原価の記録は既存処理が担当する。

対象は開発用のメモプレビュー。汎用の AI 探索、受講者への生成完了通知、実 LINE 配信、VPS 負荷計測、本番反映は別途検証が必要。

## 開発検証

使い捨て PostgreSQL と Chromium 159.0.8154.6 で「練習用メモをプレビューする」のスマートフォン版を生成した。4 手順を約 2.73 秒で操作し、前後・拡大を合わせて WebP 11 枚を保存した。検証用の同一要望からの依頼を繰り返しても 1 ジョブに収まり、画像 3 種の並行取得と準備済み教材の再利用を確認した。
