# 月と星のオラクルの限定モニター運用

現在の本番設定と開始条件は[本番準備記録](FORTUNE_PILOT_PRODUCTION_READINESS_20261121.md)、詳しい計測と停止手順は[既存の14日間の先行利用手順](FORTUNE_FAN_BUSINESS_PHASE2_PR4.md#14日間の先行利用)を参照。

## 開始判定

- 公開版の利用規約・プライバシーポリシー、公式の問い合わせ先とブランド画像を運営者が確定する。管理画面の公開準備項目を確認し、承認後に対象Serviceで登録する。
- [実AI評価](FORTUNE_REAL_AI_EVALUATION.md)で本番モデルの合成ケースを確認する。通常鑑定への切替、追質問の上限、Serviceの予算と人数を確認する。
- 先行公開と招待は別に承認を得る。運営テストアカウントでスマートフォンの通常ブラウザとLINE内ブラウザを確認する。端末が替わっても、規約確認後に年齢確認と今日の占いへ進めることを確認する。
- 承認後、18歳以上の10〜20名を14日間、限定Serviceへ招待する。週次LINEは初期OFFで始める。

## 運営テストの操作

1. スマートフォンで招待リンクを開き、ログインして招待に同意する。
2. 公開版の利用規約とプライバシーポリシーへの同意を済ませ、「サービスのホームに戻る」から「今日の占い」へ進む。18歳以上であることを確認する。
3. 初回質問は回答またはスキップを選ぶ。「AIと相談を整理してから占う」で質問に答えるかスキップし、表示された相談内容を確認して鑑定する。
4. 今日の提案を読み、希望する場合は同じ鑑定に追加で質問する。2回までの設定なら3回目は送れない。結果の当てはまりを任意で評価する。
5. 翌日、前回の提案を振り返り、保存した内容が同意の範囲内で次回に反映されることを確認する。設定で個別化・通知を停止した後も、通常鑑定が続けられることを確認する。

## 利用者画面のデザイン

占い管理の「利用者画面のデザイン」で、配色、背景、カード、見出し、装飾、ロゴ表示を調整する。スマートフォンプレビューで「今日の占い」「ヒアリング」「深層鑑定」を切り替えて確認する。

設定に満足したら「保存後に占い画面へ適用する」をオンにし、「デザインを保存」を押す。元の画面へ戻す場合は適用をオフにして保存する。ロゴURLはサービスの「基本情報・ブランド」、キャラクター画像は占い管理の「画面別のキャラクター」を使う。

## 運用中

開始前に対応者、実施日、人数、Serviceの利用枠、AI予算、問い合わせ先を記録する。毎日、初回鑑定、標準鑑定への切替、AI失敗と原価を確認する。7日目と14日目に再訪、任意評価、追加質問、振り返りを集計する。相談本文は集計に転記しない。個人情報の混入や同意の不具合があれば、既存手段で新規招待と該当機能を停止する。正式キャラクター画像は運用前の構成確認に利用でき、画像が未登録のときも鑑定手順は同じ。
