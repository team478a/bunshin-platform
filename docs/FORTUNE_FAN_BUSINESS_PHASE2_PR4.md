# AIパーソナル占い Phase 2 PR-4 と先行利用手順

## 参加者と運営者の操作

1. 参加者はスマートフォンから対象サービスに登録・ログインし、18歳以上であることを確認する。関心や相談、文体は任意で、個別化に同意して保存するかスキップできる。
2. 「今日の占い」でテーマを選ぶ。カードは1日1回。鑑定結果に「今日の提案」が表示される。AIは相談とカードに沿って、気持ちを整理する問い、人間関係や仕事の見方、短い自己理解のワークなどから、今日試せる一歩を提案する。AIが利用できない場合は承認済みの標準鑑定が表示される。
3. 条件を満たす参加者は同じ鑑定に最大2回質問できる。AI鑑定では既存の「参考になったか」と別に、自分に合っていたかを任意で評価できる。その場で変更・取消しできる。
4. 翌日以降、同意している場合は「前回の提案を振り返る（任意）」を開ける。保存した振り返りは関連する次回鑑定に活用される。設定から個別化の同意撤回、週次LINEの停止、退会ができる。
5. 運営者はサービスの「占い」管理画面で、従来の初回完了、再訪、役立ち度、振り返り、提案の自己申告、AI原価に加え、当てはまりの回答数、追加質問の利用率、週次LINE用リンクから再訪した人数を確認できる。

## 保存と集計

- 任意の当てはまり評価は `fortune_readings.personal_fit_rating` と `personal_fit_rated_at` に選択値と時刻だけを保存する。集計への回答は鑑定の個別化同意とは独立した操作で、次回のAI入力には使わない。取消しと鑑定削除で消去し、保存期限は鑑定と同じ。評価数は直近30日に保存・更新された、有効な鑑定の現時点の回答を集計する。
- 追加質問の利用率は直近30日に初めて閲覧した保持期間内の完了鑑定のうち、消去済み以外の質問がある鑑定の割合。質問ごとの成否を問わない利用指標で、同じ鑑定の2回利用は1件と数える。
- 週次LINE用リンクをログイン済みの対象サービスの参加者が開いた時点で、週次通知への同意を確認して既存の参加イベントに記録する。管理画面では直近30日の人数を重複なく数える。共通リンクのため、個別の配信記録やメッセージの開封との照合は行わない。

## 開始前の検証

- CIのブラウザテストは390×844で実際の参加者コンポーネントを使い、API応答をテスト内で差し替える。18歳確認、任意回答・スキップ、鑑定・提案、追加質問2回、評価と取消し、翌日の振り返り、個別化の同意撤回、標準結果の表示を確認する。隔離PostgreSQLの統合テストで本人・Service境界、閲覧前・削除後の制限、追加質問の同時送信、同意撤回、振り返りの次回参照を別に確認する。
- 実認証を含むローカル検証の実行方法と対象は[隔離環境での検証手順](FORTUNE_ISOLATED_AUTH_E2E.md)を参照する。
- 別途承認された隔離環境で、テストアカウントの認証から画面とDBを通した操作、実スマートフォンのLINE・通常ブラウザ双方での復帰、通知停止を確認する。届いた週次通知からの人数を管理画面で照合する。
- 実AIの文章評価は、隔離環境で合成データのみを使う実API実行を承認後に行う。同じカードで異なる相談、相談なし、関連・無関係な振り返り、追加質問、AI障害を比較する。自然さ、相談との関連、カードとの整合、提案の具体性、重要判断の断定がないこと、計上原価を記録する。原価は実行回数と参加人数で見積もり、運用責任者がService枠と既存月間予算を決める。
- 本番で利用する場合は、PR-3の `20261121010000_fortune_reading_follow_ups` とPR-4の `20261121020000_fortune_experience_quality` の適用履歴、対象production SHA、担当Bunshin、承認済み標準解釈、公開範囲、利用規約・プライバシー・問い合わせ先、AI Providerと予算、LINE設定を承認済みのリリース手順で確認する。

## 14日間の先行利用

1. 承認済みの限定公開Serviceに成人10〜20名を招待する。期間、鑑定の位置づけ、保存期間、任意回答、停止・問い合わせ方法を案内する。週次LINEは初期OFFのまま、希望者のみ設定する。
2. 開始時に対象人数、期間、AI予算、利用可能枠、運営連絡先を記録する。毎日、初回鑑定、既存の標準結果への切替、AI失敗・原価を確認する。7日目と14日目に完了・2回目・7日以内再訪、任意評価、追加質問、振り返り、提案の自己申告、LINE用リンクからの再訪を母数とともに記録する。
3. データの混入や同意の不具合を確認した場合は追加参加を停止し、対象機能またはServiceを止める。費用や失敗が運用上の枠を超える場合は既存設定でAIや追加質問を止め、標準鑑定が利用できることを確認する。通知を止める場合は既存の配信設定と予約を確認する。
4. 終了時は新規招待を終了し、希望者の通知停止・退会・削除を受け付ける。相談本文を集計資料に転記せず、少人数のため回答数と具体的な操作上のつまずきを基に改善点を決める。30日再訪率は14日間で評価せず、観測期間を満たした集計で確認する。
