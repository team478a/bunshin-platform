# OEM請求メール自動送信 実装報告

## 1. 目的

OEM月次請求の支払い案内を、運営者の手動操作だけに依存せず送信できるようにする。既存契約へ意図せず送信しないことと、同じ案内の重複送信を防ぐことを優先する。

## 2. 実装内容

- 運営団体の契約ごとに自動案内の利用可否を設定
- 初期値は停止
- 支払期限の3日前から支払い案内を1回送信
- 支払期限を過ぎた後に期限超過案内を1回送信
- 手動送信を含む監査履歴を確認し、同じ請求・同じ段階の案内を重複送信しない
- メール送信に失敗した場合は送信済み履歴を作らず、翌日の定期処理で再試行
- 有効期限内のStripe Checkout URLだけをメールへ掲載
- 接続確認済みの管理者メール設定がない場合は送信しない

## 3. 定期処理

Vercel Cronが毎日09:00（日本時間）に次の経路を呼び出す。

`GET /api/internal/commercial-billing/reminders`

この経路は既存の`CRON_SECRET`認証を必須とする。

## 4. データ変更

`organization_commercial_contracts.automatic_reminders_enabled`を追加した。既存行と新規行はすべて`false`から始まり、運営者が契約画面で明示的に有効化する。

## 5. 運用開始条件

1. 管理者メールでResend接続確認を完了し、利用中にする
2. 対象団体のOEM契約画面で自動案内を有効にする
3. 請求を「請求済み」にし、支払期限を設定する
4. 本番反映後、テスト請求で宛先・金額・期限・決済URLを確認する

## 6. 今回の対象外

- 保存カードによる無操作の自動決済
- 督促回数や送信日の団体別カスタマイズ
- 税務上の請求書作成
- SMSやLINEによる請求通知
