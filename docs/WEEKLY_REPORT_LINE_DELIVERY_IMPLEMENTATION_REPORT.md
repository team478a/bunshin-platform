# 週次レポート LINE 自動配信 実装報告

## 変更後の動作

サービス運営者は週次レポート画面で、毎週届ける曜日と時刻を選び、自動配信を開始・停止できる。初期状態は停止であり、運営者が明示的に開始したサービスだけが対象になる。

定期処理は完了した前週を参加者ごとに集計し、本人の実績要約、次の一歩、ログインが必要な週次レポート URL をLINEで届ける。投稿本文、本人素材、バッジ名、LINEユーザーIDは本文へ含めない。

## 配信境界

- ACTIVEなサービスとWorkspaceだけを対象にする。
- サービスのLINE利用と週次配信の両方が有効な場合だけ候補にする。
- 現在環境で接続確認済み、稼働中、停止されていない専用LINE設定を必須とする。
- ACTIVEかつ同意済みの一般参加者と、現在設定に接続されたFOLLOWING状態のLINEだけへ送る。
- 参加者の実績は同じWorkspace、Service、本人所有の投稿パートナーだけから集計する。
- `environment + service + weekStart`の一意キーにより、定期処理の再実行で同じ週の配信を増やさない。

## 運用画面

運営者向け週次レポート画面には、配信設定、LINE準備状況、最近8件の処理状態、送信件数、失敗件数を表示する。個別メッセージは表示しない。手動の安全な案内文作成導線も維持する。

## 本番反映後の確認

1. Migrationを適用する。
2. 専用LINEの接続確認と稼働状態を確認する。
3. 週次レポート画面で曜日・時刻を設定し、自動配信を開始する。
4. 同意済み参加者1名で受信し、本人のレポートだけが開くことを確認する。
5. 同じ日にSchedulerを再実行し、同じ週の配信履歴が1件のままであることを確認する。
