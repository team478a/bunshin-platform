# 所有者による投稿画像の試作

画像品質を先に確認したいという依頼に対応する。従来の画面は画像形式のDaily Missionが必須で、一般向けPilotは10テーマ評価などの完了記録が必要だったため、最初の試作ができなかった。

`/admin/images/samples?groupId=...`に最高管理者自身の投稿パートナーを使う試作入口を追加する。所属・同意・所有権を検証し、既存のグループ画像機能の許可と上限を適用する。一般向けPilotの開始条件や承認記録は変更しない。試作は参加者への公開・LINE配信・自動投稿を行わない。

まず1080×1350の紹介画像1枚を作る。背景は既存の管理画面OpenAI接続と画像アダプター（gpt-image-1、medium）、日本語は既存のNoto Sans JP合成処理を使う。見出し・本文・CTA・画像の雰囲気を編集できる。画像モデルの比較や10テーマの品質評価が済んだという主張はしない。

2026-09-08の初回試作では、人物や建物を含む背景は文字と競合した。既定の雰囲気は、紺色の余白、金色の細枠、端の小さな光だけを使う抽象背景へ変更した。背景モデルには、見出し・本文・CTAの各領域へ物を置かず、除外された物を補わないよう明示する。

依頼UUIDと入力ハッシュを永続化する。同じ受付番号の再送は再課金せず、入力変更や他人のUUIDは拒否する。Serializableトランザクションで試作を1日3件・月10件に制限し、失敗・削除済みも件数に含める。既存の参加者ポイントとは分離した管理者の品質検証費としてAI使用量を記録する。金額は管理設定の概算値であり実請求ではない。

完成画像と縮小画像を非公開Storageへ保存し、読み出し時にも管理者・所属・所有者を再確認する。元画像は保存しない。不要な試作は画面で削除でき、Storageを削除してからメタデータを消去する。生成中断は10分後に失敗として表示し、自動再実行しない。試作画像は自動期限削除を設けず、所有者が削除するまで非公開で保持する。

DB変更は`20260908100000_social_image_samples`。サーバー経由だけで扱うテーブルにRLSを有効化する。一般ユーザーの画像生成を完成扱いにする条件は、別途画像の品質評価・スマートフォン確認と既存Pilotの受入条件を満たすこと。
