# 本人の商品URLによる投稿文作成 実装レポート

## 目的

利用者が自分に発行された商品・代理店URLを登録し、運営者の確認後、そのURLを使ったSNS投稿文を自分で作成できるようにする。ワタシワークスの「利用者ごとにSNSコンテンツを提供し、本人が投稿する」という境界を維持する。

## 実装内容

- 参加者向け`/s/{serviceSlug}/tracking-link`に投稿文作成フォームを追加した。
- 運営者確認後に`ACTIVE`となった本人URLだけを選択肢に表示する。
- 商品・サービス名、今回伝えたいポイント、任意の対象者、投稿先を利用者が入力する。
- Instagram、X、Threadsの媒体別文字数上限内で、URLと`#PR`を含む投稿文を作成する。
- 作成後に全文を表示し、利用者が確認してコピーする。自動投稿はしない。

## 安全境界

- `DRAFT`、`SUSPENDED`、`EXPIRED`、`DELETED`のURLは投稿文へ使用しない。
- HTTPSのみを許可し、認証情報やfragmentを含むURLを拒否する。
- URL先の価格、効果、在庫等を自動取得・推測しない。
- 通常のDaily Missionやサービス紹介URLへ自動的に混入させない。
- 投稿文には`#PR`を必ず含める。
- 初期版はAI Providerを利用しないため、生成原価を追加しない。

## 検証

- Application単体テスト: PR表記、URL保持、媒体別文字数、危険URLの拒否
- Web境界テスト: ACTIVE URL限定、明示操作、手動投稿、変動情報の確認案内
- Application/Webの型検査、lint
- Next.js production build

## 後続候補

- 商品をProduct Packへ関連付け、運営者承認済みの商品情報を選択入力へする
- 分身の口調・対象SNSに合わせた個別投稿案を、明示操作時だけ生成する
- 投稿文作成・コピー・クリック・成果を商品別に集計する
- 運営者による商品ごとの禁止表現、必須表記、利用期限の設定
