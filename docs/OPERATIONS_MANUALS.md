# ワタシワークス マニュアル一覧

ワタシワークスの運用は、役割ごとに分けます。操作できない項目がある場合は、権限不足またはサービス側で機能が停止中です。

| 対象者                 | 読む文書                                                    | 主な目的                                          |
| ---------------------- | ----------------------------------------------------------- | ------------------------------------------------- |
| 利用者                 | [利用者マニュアル](USER_GUIDE.md)                           | 毎日の投稿、画像・動画、紹介URL、ポイント         |
| サービス管理者         | [サービス管理者マニュアル](SERVICE_ADMIN_GUIDE.md)          | 参加者、ナレッジ、LINE、商品、投稿承認、動画配信  |
| プラットフォーム管理者 | [プラットフォーム管理者マニュアル](PLATFORM_ADMIN_GUIDE.md) | サービス作成、全体設定、秘密情報、販売プラン、OEM |

## 共通ルール

- 秘密情報を画面のメモ、CSV、チャット、問い合わせへ貼り付けない。
- SNS・画像・動画は自動で公開されません。承認・投稿の最終確認は人が行う。
- 他サービス・他参加者のデータは見ない、混ぜない。
- 異常時は削除より先に停止し、履歴と影響範囲を確認する。
