# サービス管理操作後の遷移統一 実装報告

## 完成した操作

- 参加者の利用機能設定
- 参加者の役割・状態変更
- サービス参加申請の承認
- 法務文書の下書き保存・公開
- バッジ案の申請・付与候補登録・候補審査

サービス専用管理画面から上記を実行した場合、成功・入力エラー・権限エラーのいずれも同じサービス専用画面へ戻る。

## 安全設計

- フォームへ任意の戻り先URLを保存しない。
- 引き継ぐ値はService Slugだけに限定する。
- Server ActionがService Slug、Group ID、サービス状態、Group状態、Workspace状態の一致をDBで再確認する。
- 不正・古い・他サービスのSlugは採用せず、既存のGroup管理URLへフォールバックする。
- 保存処理自体のWorkspace、Group、Actor権限検証は既存Use Caseで継続する。
