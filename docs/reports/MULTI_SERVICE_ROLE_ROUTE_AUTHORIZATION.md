# サービス管理入口の役割別認可

更新日: 2026-08-31  
対象: MS-2D-S3-A

## 完了したこと

- サービス管理用の共通認可を`SERVICE_OWNER / SERVICE_ADMIN`へ統一
- 設定、LINE、参加者、公式資料、法務、バッジ、公式商品、参加募集、専用URLの全管理入口へ適用
- サービスホームの管理メニュー表示も同じ役割で判定
- 旧`GroupRole.MANAGER`だけではサービス管理画面へ入れないように変更
- Service Slug、Active Service、Active Workspace、Active Membershipを共通処理で再検証

## 現在の役割

- サービス所有者: すべてのサービス管理入口を利用可能
- 運営管理者: すべてのサービス管理入口を利用可能
- コンテンツ担当者: 管理入口はまだ利用不可
- 一般参加者: 管理入口は利用不可

## コンテンツ担当者をまだ開放しない理由

画面だけを表示しても、商品・募集・公式資料のRepositoryが旧管理者認可のままでは保存時に失敗する。S3-Bで対象Repository、API、画面を同時に変更し、コンテンツ関連だけを安全に開放する。
