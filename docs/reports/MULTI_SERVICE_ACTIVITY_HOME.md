# サービス専用 活動ホーム 実装報告

## ゴール

サービス参加者が専用ホームを開くだけで、今週どこまで進んだかを確認し、そのまま今日の投稿案へ進めるようにする。

## 実装内容

- サービス専用ホームへ「今週の進み具合」を追加
- 投稿パートナーごとに、進んだ日数、週間目標、曜日別の状態を表示
- 初めての利用者には投稿パートナー作成を案内
- SOCIAL未準備時は、投稿パートナー確認へ案内
- 「今日の投稿案を見る」からサービス専用詳細画面へ移動

## データ境界

進捗の取得には、画面入力ではなくサービスSlugからサーバー側で解決した`workspaceId`と`groupId`を使用する。さらにログイン利用者の`actorUserId`と本人所有の`bunshinId`を照合する。

個人向けの進捗、他サービスの進捗、同じサービスの他参加者の進捗は表示しない。

## 今回含めないもの

- サービス専用LINE通知からの署名付き遷移
- バッジの自動付与
- サービス間をまとめた活動表示
- サービス管理者による個人進捗の閲覧

LINE導線は、共通LINE、サービス専用LINE、企業独自LINE、OEM LINEの採用方針を確定した後に、サービスIDを署名付きstateへ含めて実装する。

## 検証

- サービスIDがCapability確認と進捗Repositoryへ伝播すること
- ログイン利用者IDをサーバー側で使用すること
- サービス専用ホームに週間進捗と投稿案への導線があること
- 個人向け`/today`へ誤って遷移しないこと
