# サービス管理者向けブランド・登録設定

## 実装範囲

サービス運営管理者が、自サービスの名称、説明、運営者、問い合わせ先、ロゴ、アイコン、色、文字、規約URL、参加方法を管理画面から更新できるようにした。

サービス専用URL、公開状態、利用期間、`Powered by ワタシワークス`表示はプラットフォーム管理項目として維持し、サービス管理者は変更できない。

## 境界

- Service Slugはサーバー側で解決する。
- ACTIVEなService Manager Membershipを必須とする。
- 非公開の準備中サービスも、所属管理者だけは設定できる。
- HTTPでプラットフォーム管理項目を受け取らない。
- RepositoryでもSlug、公開状態、期間、Powered byの差し替えを拒否する。
- 変更前後と変更理由は既存のService Configuration Auditへ保存する。
- 表示名変更時は内部Group名も同期する。

## 対象外

画像ファイル自体のアップロード、独自ドメイン、契約変更、サービス停止、秘密鍵・APIキー管理は本実装へ含めない。
