# サービス公開・利用管理 実装報告

## 目的

プラットフォーム管理者が、DBやサーバーを直接操作せず、サービスの公開と停止を日常運用できるようにする。

## 管理できる項目

- 公開／非公開
- サービスの一時停止／再開
- 利用開始日時
- 利用終了日時
- 「Powered by ワタシワークス」の表示
- 変更理由

## 権限とデータ境界

- 更新できるのは有効なSUPER_ADMINだけとする。
- クライアントからWorkspace IDやGroup IDを受け取らない。
- Service Configuration IDを基に、WorkspaceとGroupをサーバー側で解決する。
- サービス管理者向け設定APIでは、従来どおり公開状態、利用期間、Powered by表示を変更できない。
- ARCHIVED状態はこの画面から再利用せず、復旧を伴う別の管理判断とする。

## 監査

変更前後の公開状態、利用状態、利用期間、Powered by表示と、変更理由、実行者を`ServiceConfigurationAudit`へ保存する。APIキーやLINE秘密値などは監査対象に含めない。

## UI

`/admin/services`の各サービスを開くと、現在の状態と変更フォームを確認できる。保存中、保存完了、失敗を画面内に表示する。一時停止の影響も日本語で説明する。
