# サービス専用SNS戦略 接続記録

## 完了範囲

- サービス専用の投稿パートナー詳細画面からSNS戦略を生成・一覧表示・承認できる。
- サービスSlugからWorkspaceとService（内部Group）をサーバー側で解決する。
- SNS戦略の参照・生成・承認を、対象サービスに所属する投稿パートナーの所有者本人に限定する。
- 既存の個人向けSNS戦略APIとデータを維持する。

## データ分離

SNS戦略自体にはGroup IDを重複保存せず、紐づく投稿パートナーからサービスを判定する。Repositoryは`workspaceId`、`groupId`、`bunshinId`、`actorUserId`を同時に検証する。個人向け呼び出しは`groupId = null`として扱うため、サービス側の戦略へ到達しない。

生成時に使用するSNS設定も同じサービス境界で取得する。サービス用Knowledge Grantが接続されるまではKnowledgeを生成入力へ渡さず、個人または別サービスの知識が混ざることを防ぐ。
