# サービス専用招待導線 実装報告

## 利用の流れ

1. サービス管理者が参加者管理画面で役割を選ぶ。
2. 1人だけが7日以内に使えるサービス専用招待リンクを発行する。
3. 招待された本人がサービス名・運営者・役割を確認する。
4. LINEまたはメールでログイン後、参加を承諾または辞退する。
5. 承諾後はサービスホームへ移動する。

## 分離と安全性

- 招待URL発行前にService Slug、Workspace、Groupの一致を検証する。
- 承諾・辞退前にも招待Tokenが同じサービスのGroupに属することを再検証する。
- Tokenは43文字の短期・一回限りの既存仕様を維持する。
- LINEログインの戻り先は完全一致パターンだけを許可し、任意クエリとOpen Redirectを拒否する。
- 既存Group招待は移行互換性のためそのまま利用できる。
