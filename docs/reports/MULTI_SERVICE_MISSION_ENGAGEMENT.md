# サービス専用 投稿行動接続 実装報告

## 完了したこと

- 投稿案の採用・不採用と不採用理由
- 採用後の投稿文、画像指示、動画指示、撮影台本、スライドのコピー
- 本人による「投稿しました」の記録
- 投稿後の「自分らしい・普通・違う」Feedback
- 投稿案を開いた行動の記録
- 保存済みの判断、投稿日時、Feedbackの再表示

## データ分離

操作対象はURLやブラウザー入力から決めない。サービスSlugをサーバー側で解決し、次のすべてが一致する場合だけ処理する。

- Workspace
- Service（内部Group）
- ログイン利用者が所有するBunshin
- Daily Mission

Mission Decision、Activity、PostRecord、Feedbackのリポジトリにも同じService・Owner境界を追加した。別サービス、別利用者、個人用Bunshinの記録を読み書きできない。

## 操作の順序

1. 投稿案を確認する
2. 「採用する」または「今回は使わない」を選ぶ
3. 採用した場合だけ必要な内容をコピーする
4. 本人がSNSへ手動投稿する
5. 「投稿しました」を押す
6. 投稿が本人らしかったかを回答する

SNS自動投稿、SNS OAuth、成果指標の自動取得は追加していない。
