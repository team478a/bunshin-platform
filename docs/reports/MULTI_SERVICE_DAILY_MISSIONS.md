# サービス専用「今日の投稿案」接続記録

## 完了範囲

- サービス専用の投稿パートナー画面から、確定済み週間投稿計画を基に今日の投稿案を生成できる。
- 企画、作り方、そのまま使える文章・台本・生成指示を画面で確認できる。
- サービスSlugからWorkspaceとService（内部Group）をサーバー側で解決する。
- 投稿案の参照・生成を、対象サービス内の投稿パートナー所有者本人に限定する。
- 個人向けの投稿案生成・学習・商品案件機能を維持する。

## 安全な生成コンテキスト

サービス版は、同じサービス境界の投稿パートナー、SNS設定、承認済みSNS戦略、投稿テーマ、確定済み週間投稿計画だけを使用する。サービス用の接続境界が未完成の個人Knowledge、Memory、Personality Version、Trend、Product Pack、Campaignは生成入力から除外する。

## 次の作業

サービス境界を持つ採用・不採用、コピー、投稿完了、Feedbackを接続する。その後、サービス用Knowledge GrantとCampaignを明示的な許可境界のもとで生成へ追加する。
