# 画像作成回数の消費接続 実装報告

## 動作

サービス参加者が投稿用画像を作る操作を確定すると、サービス別画像作成回数の口座がある場合は1回を消費します。

- 残り回数が0の場合は、画像作成を開始しません。
- キュー登録までに失敗した場合は、消費した1回を返却します。
- 同じ画像作成依頼の再試行では、同じ依頼IDを冪等キーに使うため二重消費しません。
- 台帳には消費・返却・操作後残高を追記し、既存履歴は書き換えません。

## 既存サービスとの互換性

画像作成回数の口座を持たない既存サービスは、従来どおりバッジ利用権またはワタシワークスポイントで画像を作れます。
画像作成回数の口座があるサービスでは、回数を優先して使い、ポイントと二重に消費しません。

## 分離

消費・返却ともに、ワークスペース、サービス、参加情報、ユーザーを一致させます。
別サービスや別参加者の画像作成回数は利用できません。

## 後続範囲

- 期限到来した付与回数の自動失効
- 購入による画像作成回数の付与
- 消費状況を使った運営レポート
