# OEM登録完了メール 実装報告

各OEMサービスが、登録・承認完了後の案内メールを独自に管理できるようにした。

- サービス単位で送信有無、件名、本文、送信者名、送信元、返信先を設定できる。
- `{{name}}`と`{{serviceName}}`を本文・件名へ使える。
- ワタシワークス共通メール基盤、またはOEM自身のResend APIキーを選べる。
- 専用APIキーは暗号化して保存し、画面には末尾4桁のマスクだけを返す。
- テスト送信に成功するまで配信を開始しない。
- 登録・承認時に冪等な配信キューを作り、5分ごとの内部処理で最大3回まで送信を試みる。
- 送信済み、失敗、再試行回数、送信日時をサービスごとに記録する。

認証用のメールマジックリンクはSupabase認証の責務として維持し、登録完了案内とは別管理にする。
