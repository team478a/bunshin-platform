# ワタシワークス 利用者マニュアル

この文書は、サービスに招待された参加者向けです。SNSへの自動投稿は行いません。内容を確認・コピーし、ご本人が投稿します。

## 毎日の使い方

1. サービスから届いた案内を開き、ログインします。
2. 初めての場合は、表示名・使うSNS・発信の目的などを入力します。
3. 「分身を作る」から、質問に答えて投稿人格を作ります。迷った場合は選択肢を選んでください。
4. 「今日の投稿」を開きます。投稿案は、文章、画像案、動画案、撮影案のいずれかです。
5. 内容を確認して、まず「採用する」または「今回は使わない」を選びます。
6. 採用後に表示されるコピー操作で、投稿文・スライド案・動画生成用の指示文をコピーします。
7. 必要に応じてCanva等で画像を作る、または外部の動画生成サービスで動画を作ります。
8. ご自身のSNSへ投稿し、ワタシワークスで「投稿しました」を選びます。
9. 投稿が自分らしかったかを3段階で答えます。

## 画像・動画を使うとき

- 画像作成では、表示された案を確認してから作成を依頼します。完成した画像はダウンロードしてSNSへ投稿します。
- 動画作成では、企画、台本、場面案を確認して承認します。動画の完成まで時間がかかることがあります。
- 配信された動画は、URLの有効期限と利用条件を確認してください。停止済みの動画は使わないでください。
- 人物・商品・音楽・ロゴなど、第三者の権利を侵害する素材は使用しません。

## 紹介URLが入った投稿

商品紹介の投稿では、管理者が設定したあなた専用の紹介URLが入ることがあります。

- URLは本文から削除・別の人のURLへの置換をしないでください。
- URLが見つからないという表示が出た場合は、管理者へ連絡してください。
- 成果、報酬、購入者情報はワタシワークスでは管理しません。外部の紹介・代理店サービスが正しい記録です。

## ポイント・バッジ・紹介

- ポイントやバッジは、サービスごとに別々に管理されます。他のサービスへ移すことはできません。
- 紹介リンクは、画面に表示されたものだけを利用してください。特典の条件や上限はサービスごとに異なります。
- 獲得状況に疑問がある場合は、サービス管理者へ問い合わせます。

## 困ったとき

| 状況                           | まずすること                                               |
| ------------------------------ | ---------------------------------------------------------- |
| ログインできない               | LINEログインまたはメールのログインリンクをもう一度試す     |
| 投稿案が表示されない           | 分身・SNS設定・サービスの参加状態を確認する                |
| 画像や動画の作成が止まっている | 少し待って再読み込みし、続く場合はサービス管理者へ連絡する |
| 投稿後に修正したい             | SNS側で修正し、必要なら「今回は使わない」理由を記録する    |
| 退会したい                     | アカウント画面の退会手続きから申請する                     |

## 大切な注意

- ワタシワークスは収益・反応・成果を保証しません。
- SNSへの投稿と最終確認は、ご本人の責任で行います。
- 他の参加者の投稿、人格、紹介URL、ポイントは見られません。
