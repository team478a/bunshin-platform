# OEM採算確認 実装報告

## 1. 調査した内容

- Workspace単位のMAU計測と料金判定
- Workspace単位のAI使用量・見積原価記録
- システム管理者向け請求・入金管理画面
- OEM運営団体を越える情報を閲覧できる権限境界

## 2. 変更した内容

- OEM運営団体ごとの当月MAU、料金見込み、AI見積原価を集計
- 原価設定済み・未設定のAI処理件数を分けて表示
- 全OEM運営団体を横断する「OEM採算確認」画面を追加
- 各団体の契約・請求画面への導線を追加

## 3. 主要な設計判断

- MAU料金は円、AI原価は米ドルのまま表示し、固定為替を使った架空の利益額を算出しない。
- 決済手数料、人件費、画像・動画など別基盤の原価は含まないことを画面に明示する。
- 横断画面はPlatform `SUPER_ADMIN`だけが閲覧でき、OEM運営者には他団体の数値を公開しない。
- 原価未設定のAI処理を隠さず、単価設定の要確認件数として表示する。

## 4. 検証

- WorkspaceごとにMAUとAI原価が分離される単体テスト
- Platform `SUPER_ADMIN`境界と表示上の注意書きのテスト
- TypeScript、lint、format、差分検査

## 5. 今回の対象外

- 為替レート設定と円換算利益
- 人件費、決済手数料、画像・動画Provider原価の統合
- 月次採算スナップショットとCSV出力
