# 千ノ国メディア 日次投稿重複修正

## 確認結果

日次Mission自体は日付単位で一意だが、AI生成失敗時の予備投稿は同じ投稿分類に対して固定文を返していた。また通常生成では、直近7日間の本人の投稿内容と完全一致した場合に保存を止める検査がなかった。

## 修正内容

- 予備投稿でも配信日ごとに投稿の切り口を変更
- 予備投稿でも配信日ごとに画像用の撮影指示を変更
- 通常のAI生成結果が本人の直近7日間の投稿内容と完全一致した場合は不採用にする
- 完全一致だけでなく、直近投稿と95%以上類似する内容も不採用にする
- AIへ本人の直近7日間のテーマを渡し、言い換えだけの企画を避ける
- 週間計画内で同じ目標・切り口を重複させない
- 予備投稿は配信日とBunshinの組み合わせで変化させ、同じ日でも利用者ごとに切り口を分ける
- 重複不採用時は既存の安全な予備投稿経路へ切り替える

## 影響範囲

千ノ国メディアを含む日次投稿支援サービスに適用する。比較対象は同じWorkspace・同じBunshinだけであり、他の利用者の投稿内容を参照しない。

## 横断監査

- 日次MissionはDBでWorkspace・Bunshin・日付の一意制約があり、同じ日の二重作成を防止済み。
- LINE配信はMission IDを含む冪等キーを使用し、同じ配信処理の二重送信を防止済み。
- 投稿の再生成は元投稿との類似度85%以上を拒否済み。
- 商品Campaignは過去投稿との類似検査を実施済み。
- 画像・動画は対象の日次Mission IDへ紐付き、別日の成果物を暗黙再利用しない。
- 今回不足していた通常投稿の直近類似検査、週間計画内の重複検査、過去4週間の企画参照、予備生成の利用者別変化を追加した。
