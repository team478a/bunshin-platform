# 活動継続 J3-A 実装報告

## 完成した範囲

- これまでの活動日数から、下がらない発信ステップを表示する。
- 初回確認、初回準備、初回投稿、3日活動の達成バッジを一度だけ付与する。
- バッジのルール版、表示名、説明を付与時点の記録として保存する。
- 最終活動日から7日以上の場合、Web画面に負担を与えない復帰案内を表示する。
- Workspace、User、Bunshin、Feature Keyをすべて照合し、別利用者や別分身のバッジを参照・付与しない。

## 保存するものと保存しないもの

保存するのは、付与済みバッジと付与日時だけである。発信ステップ、累積日数、休眠状態は既存のMission Activityから都度計算する。順位、比較、ポイント、報酬、連続日数による減点は保存も表示もしない。

## 版管理

初版はRule Version 1とする。同じ版・同じバッジはDB一意制約とRepositoryのupsertで重複付与を防止する。将来条件や文言を変更する場合は版を上げ、過去に付与したSnapshotを変更しない。

## 次の実装

J3-Bでは、既存LINE通知の同意、Quiet Hours、月間Quota、全体停止、重複送信防止を再利用して復帰通知を接続する。J3-Aでは外部送信を行わない。
