# OEM請求案内モニター 実装報告

## 1. 目的

複数のOEM運営団体で発生した自動請求案内の送信失敗を、システム管理者が全体の請求画面から見落とさず確認できるようにする。

## 2. 実装内容

- 請求中の請求記録に関係する案内送信履歴を全運営団体から取得
- 請求、運営団体、案内種別ごとに最新の送信結果を判定
- 後続の送信成功がない失敗だけを未解決として表示
- 全体画面に未解決件数、対象団体、請求番号、案内種別を表示
- 「案内送信失敗」絞り込みを追加
- 団体別請求画面の確認・手動再送へ直接移動できるリンクを追加

## 3. データと権限

新しいテーブルやmigrationは追加しない。既存の`CommercialBillingAudit`と`TenantInvoice`を利用する。画面は従来どおりPlatform `SUPER_ADMIN`だけが利用でき、運営団体の請求先情報を一般利用者へ公開しない。

## 4. 解消条件

失敗した案内と同じ案内種別で後から送信成功履歴が記録されると、未解決一覧から自動的に除外する。取消・入金済みの請求は監視対象外とし、現在も請求中の記録だけを対象にする。

## 5. 運用

未解決が表示された場合は、対象団体の画面で管理者メール設定と請求先メールを確認し、既存の手動送信ボタンで再送する。翌日の自動処理でも再試行される。
