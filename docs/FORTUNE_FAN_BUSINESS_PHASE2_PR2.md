# AIパーソナル占い Phase 2 PR-2

- 基準はPR-1マージ後の `main`（`70c893ae`）。既存の `FortuneServiceSetting.guidanceSettings` に任意の案内役詳細を保存する。旧JSONの設定は引き続き読める。DBマイグレーションは不要。
- 運営者は「占いの公開準備」→「ヒアリングとAI案内役の設定」で表示名、紹介文、性格、言葉遣い、鑑定の表現ルール、質問・提案の方針、HTTPSの画像URLを設定できる。既存のサービスと権限の境界を使用する。
- `/s/{serviceSlug}/today` で、機能を有効にしたサービスの案内役をAIとして表示する。年齢確認、任意の初回ヒアリング、抽選、今日の結果の順に、現在の状態に合った操作を案内する。鑑定後は今日の結果・提案を先に表示し、同意済みの任意の振り返りや過去結果を続けて確認できる。Noto Sans JPはWebアプリから配信する。
- 鑑定は同じServiceの案内設定を参照する。表示用の紹介文と画像URLはAIへ渡さない。今回の相談、本人が選んだ鑑定スタイル、既存の安全性と構造化出力を優先する。
- 検証対象は旧設定の互換性、画面の状態別表示、設定API、本人スタイルの優先、既存の鑑定生成と分離。本番への反映、実機・実AIの品質確認は別作業。PR-3では同じ鑑定に紐づく追加質問を実装する。
