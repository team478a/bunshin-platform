# 深層パーソナル占い Phase 3 PR-1

## 既存機能と差分

作業開始時の `main` は `11cf516a`（#1552）で、#1542〜#1552で統合された通常鑑定、プロフィール、同意済み履歴・Memory、鑑定後の追加質問、行動提案、振り返り、品質画面がある。作業中に #1553 の隔離認証テストが統合されたため、`c0436555` を基点とした。既存の抽選、鑑定生成、保存、LINE、Service分離を再利用する。作業開始時の `production` は `28026d86`（#1547）。この確認はGit上の反映範囲を示す。本番DBの適用履歴、サービス別フラグ、実際の稼働は別の確認対象。

Phase 3 PR-1では、鑑定前にAIが承認済みの候補から未質問の1問を選ぶか、終了を返す。既知の情報を聞き直さないよう、本人の今回の相談、回答済み・スキップ済みの項目と、有効な同意のあるプロフィールを比較に使う。追加質問の最大数とAI呼び出し上限はServiceごとに設定し、既存のService・組織Quota、Provider Admission、占い原価記録を使う。原価の内訳は `fortune-dynamic-intake-v1` で識別できる。

## 操作

1. 運営者は「占い」管理画面の「ヒアリングとAI案内役の設定」で動的ヒアリングを有効化し、追加質問数とAI利用上限を設定する。初期OFF、既定は各3回、最大5回。既存のAI鑑定と個別化が有効なときに表示される。
2. 18歳確認済みの参加者は「今日の占い」から「AIと相談を整理してから占う」を選び、テーマと任意の相談を入力する。質問には候補または自由入力で回答でき、スキップや通常の占いへ戻る操作も選べる。
3. 「ここまでで占う」で、入力済みの回答を今回の相談として既存の鑑定に渡す。AIで質問を選べないときも通常の鑑定で続けられる。同じ日の鑑定がある場合は既存結果が使われる。

## 保存と検証

- `fortune_intake_turns` に質問コード・選択したテーマ・順番・日時を保存する。同じ参加者の同じ日本日の同じ順番は一意とし、再送では選択結果を返す。自由回答はこの表に保存せず、前日以前の選択記録は既存の占い期限処理で削除する。
- 合成AI出力のテストは候補外・既出・余計なフィールドの拒否、停止判断、権限変更時の未送信、原価記録を確認する。隔離DBテストは参加者・Service境界、同時実行、回数、再送、同日の鑑定後、期限切れを確認する。スマートフォン幅のブラウザテストは候補タップ、質問のスキップ、質問選択に失敗しても鑑定できる操作を確認する。
- 実AIでの質問品質・費用は別途承認された環境で確認する。本番公開、productionマイグレーション、実ユーザーへの通知はこのPRの範囲外。

PR-2では、本人が伝えた事実、希望、未確認の推測を分け、鑑定前に本人が確認・訂正できるようにする。
