# AIキャラクター基準画像アップロード（AV-4C1）

## 目的

サービス管理者が、公開済みのAIキャラクター生成設定に基準画像を登録し、画像・動画生成時に同じキャラクターを再現しやすくする。

## 実装内容

- サービス管理画面の「AIキャラクター」で、公開済みの生成設定ごとに基準画像を登録できる。
- 対応形式はJPEG、PNG、WebP。上限は20MB。
- ファイル名、サイズ、ブラウザが申告した形式だけでなく、画像データ先頭の形式も検査する。
- 保存先はSupabase Storageの非公開バケット `ai-character-references`。
- 保存キーは `workspaceId/groupId/versionId/UUID` とし、他サービスの画像を参照できない。
- 保存後に、SHA-256、サイズ、形式、権利確認日時、登録者をDBへ記録する。
- DB記録に失敗した場合は、保存した画像を削除して孤立ファイルを残さない。
- 登録済み画像は、ログイン済みかつ該当サービスの管理権限を持つ利用者へだけ、認証済みAPI経由で表示する。

## 権利と安全性

- 登録時に「AI生成に利用できる権利を確認した」チェックを必須にする。
- 画像は公開URLを発行しない。`Cache-Control: private, no-store`、`nosniff`、sandbox CSPを付与して表示する。
- アップロード、表示ともにworkspaceId・serviceId・公開済みversionIdをサーバー側で検証する。
- アップロード成功は監査ログ `REFERENCE_ASSET / UPLOADED` として残す。

## 今回の対象外

- 参照画像の削除・置換UI
- 顔照合、肖像権の自動判定、成人性判定
- 基準画像を実際の動画レンダリング要求へ添付する接続
