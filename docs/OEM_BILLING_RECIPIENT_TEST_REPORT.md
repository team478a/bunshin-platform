# OEM請求先メール テスト送信実装報告

## 1. 目的

OEM月額請求の運用開始前に、保存した請求先メールアドレスへ実際にメールが届くことを確認する。請求書や決済を作成せず、安全に送信経路だけを検証できるようにする。

## 2. 実装内容

- システム管理者だけが運営団体の商用管理画面から実行できる
- 保存済みの請求先名と請求先メールを使用する
- 件名で接続確認であることを明示する
- 本文で支払いや操作が不要であることを明示する
- 接続確認済みで利用中の管理者メール設定を使用する
- 同一契約・同一日は送信サービスの冪等キーを共通化する
- 成功と失敗を契約の監査履歴へ保存する
- 認証情報、メールサービスの応答本文、請求情報は監査履歴へ保存しない

## 3. 操作手順

1. 運営団体の「OEM契約と請求先」で請求先を保存する
2. 表示された保存済みメールアドレスを確認する
3. 「請求先へテストメールを送る」を押す
4. 画面の成功表示と受信メールを確認する
5. 契約・請求の変更履歴で送信記録を確認する

## 4. 運用上の境界

テスト送信は請求書の発行、請求台帳の作成、決済URLの発行、入金状態の変更を行わない。宛先を変更する場合は、先に契約・請求先を保存してから再実行する。

## 5. 検証

- テストメールの宛先、件名、本文、冪等キー
- メールサービス拒否時の失敗処理
- 契約保存フォームとテスト送信フォームの分離
- 成功・失敗の監査履歴と画面表示
