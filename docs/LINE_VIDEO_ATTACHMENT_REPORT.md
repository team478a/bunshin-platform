# 完成動画のLINE添付

## 対象

個別作成動画と毎日の自動字幕動画について、本人向け完成通知に動画メッセージを添付する。動画と確認リンクを一度のpushで送る。運営者による動画配布通知は従来のリンク通知を維持する。

## 実装

- 既存の通知許可、LINE接続、配信停止、残枠、完成から23時間の再送期限を通過した後に添付を準備する。
- Workspace・Group・Owner・Bunshin・Projectを指定し、完成済み、未削除、未期限切れ、中止されていない動画だけを対象にする。保存パスも所有範囲と一致することを確認する。
- 非公開StorageのMP4に24時間の署名URLを発行する。動画保存時の既存上限100MBはLINEの上限200MB以内。保存期限が24時間以内の動画はリンク通知のみとする。
- プレビューは540×960の共通再生カバーPNG。個人情報や動画フレームを含めず、LINEのプレビュー上限1MBと縦横比9:16に合わせる。
- 初回送信前に宛先、認証情報のハッシュ、タイトル、リンク、添付URL、再送キーをDBへ保存する。同時実行時は最初に保存された内容を採用し、再試行で内容を変えない。認証キーや宛先が変わった場合は送信しない。
- 保存した通知情報を汎用の動画レコード返却から除外する。平文APIキーは保存しない。署名URLは期限付きの閲覧権限なのでログへ出力しない。
- 旧通知の再送はリンク形式を維持する。新しい完成通知のみ添付を追加し、受付済みの動画を再通知しない。

## DBと検証

`20260907160000_video_notification_snapshot`で`video_renders.notification_snapshot`を追加する。既存行はNULL。DBマイグレーションは本番アプリ反映前に適用する。

添付とリンクの一括送信、不正URL拒否、宛先・認証変更拒否、同時実行の保存結果共有、再試行時の本文固定、旧通知互換、失効動画拒否、PNG形式・容量・寸法をテストする。実際のLINE送信は行わない。

## 運用確認・残作業

CI・マイグレーション反映後、限定アカウントでLINE受信、再生、確認画面への移動を確認する。署名URL失効後は確認画面から動画を取得する。LINEの端末キャッシュや再生は実機確認が必要で、永続再生は保証しない。

動画内容を使ったサムネイル、運営者からの配布動画への添付、毎日のAIキャラクター動画は別作業。動画のSNS投稿・採用判断は自動化しない。
