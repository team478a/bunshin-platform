# OEM一括導入 実装報告

システム管理者が1回の操作で、運営団体、OEM権限、標準利用上限、非公開サービス、ブランド初期値、登録方針、下書き契約、先方管理者の招待を作成できるようにした。

全データは1つのDB transactionで作成するため、途中失敗時に不完全な運営団体を残さない。サービスは必ず非公開、契約は下書き、自動督促は停止状態から開始する。

LINE資格情報、Stripe資格情報、利用規約・プライバシーポリシー、独自ドメイン、本番公開は自動設定しない。先方管理者の招待URLを表示し、各設定画面で確認してから公開する。

招待された運営管理者が参加すると、OEM運営団体に属する既存プロジェクトへSERVICE_ADMINとして追加する。一般参加者にはこの権限を付与しない。
