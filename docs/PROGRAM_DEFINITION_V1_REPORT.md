# Program Definition V1 実装記録

## 目的

既存の `ProgramTemplateVersion.definition` を、自由形式のJSONから検証済みの版付き定義へ変更した。既存Programモデルを正本として維持し、副業90日プログラムを別システムとして増設しない。

## 実装内容

- `schemaVersion: 1` を持つProgram定義型と検証処理
- 固定期間、支援方法、標準ルート、段階、行動、通知方針、成果項目の検証
- 重複キー、存在しない段階・ルート参照、期間の重複、未定義の完了イベント等を公開前に拒否
- 既存の副業90日プログラムを、4段階・曜日別28行動・4成果項目として定義
- 汎用のシンプルな毎日実践プログラム定義
- システム管理画面で定義の型を選択し、公開済み定義の期間・段階・行動・成果数を確認できる表示
- `ProgramCoreService` から公開する場合も同じ検証を適用

## 互換性

DB変更はない。過去に公開済みの自由形式JSONは削除・書換えを行わず、管理画面では「旧形式」と表示する。今後作成する第1版と、新版を公開する処理にV1検証を適用する。

## 次のゴール

EnrollmentごとのMission配信実績、行動イベント、進捗スナップショットを追加する。これにより開始日・現在の段階・次の行動を、事業プロフィール作成日ではなくProgram Enrollmentを基準に計算できるようにする。
