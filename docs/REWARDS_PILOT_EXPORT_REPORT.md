# ポイント・バッジ試験結果CSV 実装報告

## 目的

4週間の試験結果を運営判断、打ち合わせ、記録に使えるファイルとして保存できるようにする。

## 出力内容

- 設定された試験開始日時と終了日時
- 開始前、実施中、終了、期間未設定の状態
- 試験参加者数、投稿率、3日以上の継続率、ポイント交換率
- 投稿数、付与ポイント、利用ポイント、確認候補数
- 参加者ごとの投稿、継続、交換、ポイント量、確認理由

試験終了後は、画面と同じく終了日時で集計を固定する。期限切れになった参加者も、試験期間と参加期間が重なっていれば結果へ残す。

## 操作

サービス管理の「ポイントとバッジ」を開き、「試験運用の結果」にある「4週間の試験結果を保存」を押す。CSVはExcelやGoogleスプレッドシートで開ける。

CSVには参加者名とメールアドレスを含むため、サービス運営者だけが取得できる既存の認可経路を使用する。
