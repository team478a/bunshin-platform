# グループバッジ管理画面・CSV 実装報告

## 実装範囲

- グループ管理者によるバッジ案の作成と本部への同時申請
- システム管理者による承認・差戻し
- 参加者の付与候補登録と、別管理者による承認・見送り
- `email,badge_code,reason` 形式のCSV部分取り込み
- 正常行の登録継続と、エラー行・理由の画面表示
- 管理画面およびグループ一覧からの導線

## 権限と分離

- バッジ作成・候補登録・候補審査は有効なグループ管理者だけが行う。
- バッジの利用開始は有効な `SUPER_ADMIN` だけが承認する。
- CSVの参加者・バッジ検索には必ず `workspaceId` と `groupId` を含める。
- 候補者本人および推薦者本人は付与を承認できない。
- 個人の知識、人格、メモリー、通常投稿は参照しない。

## 固定した安全方針

- グループバッジは `MANUAL_APPROVAL`、公開範囲は `GROUP`、報酬は `NONE` とする。
- 作成・版作成・承認申請・監査記録は一つのDBトランザクションで保存する。
- CSVは最大500行、500KBまでとし、不正な見出し・メール・コード・理由を行単位で拒否する。
- CSVの一行が失敗しても、他の正常行は登録する。

## 対象外

- バッジによるポイント・金銭・商品報酬
- 自動付与条件のグループ独自作成
- 他グループへのバッジ共有
