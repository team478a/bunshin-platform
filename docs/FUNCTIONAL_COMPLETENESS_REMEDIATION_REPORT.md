# 機能完成度監査の是正

## 今回の目的と範囲

2026-09-07の機能完成度監査を受け、利用者が未提供機能を利用可能だと思って操作する状態と、退会完了判定の不足をまとめて修正する。写真合成・音声生成等の提供予定は取り下げず、実装が完了するまでの公開範囲を実態に合わせる。

## 変更

### 動画

- 標準動画の表示を「字幕動画（背景と文字・音声なし）」に変更。写真スライドの新規作成を画面とAPIで止める。
- 動画企画の出力スキーマとプロンプトを TEXT_MOTION / AI_VIDEO、SCRIPT_GENERATION / VIDEO_GENERATION に限定。Prompt Version を更新。
- 写真・音声等の未対応処理を含む企画を、保存時、レンダー受付時、ワーカー実行時、合成時に拒否。背景だけの動画を成功扱いすることを防ぐ。
- 古い企画には作り直しの案内を出す。参考台本は音声出力しないことを動画詳細にも明記。
- 既存の字幕動画・FALのAI動画は維持する。

主なファイル: `packages/application/src/video-core.ts`、`packages/database/src/index.ts`、`apps/web/src/providers/openai-video-plan-generator.ts`、`apps/web/src/providers/creatomate-video-render.ts`、動画作成・詳細画面。

### 退会

- 既存の退会処理に、本人所有の動画素材、生成画像、完成動画、AI動画シーン、画像生成の参照写真の Storage 削除を接続。
- 所有者と保存キーの範囲を照合し、別ユーザーのキーは削除しない。
- Storage削除が成功してから削除状態を記録する。失敗したキーは保持して、処理リースが再取得された後に再試行する。
- 1種類20件ずつ処理し、続きがある間は PROCESSING として完了させない。
- 素材がある場合はアカウント停止から24時間待ち、既存のアップロードURL・最大300秒のワーカー処理と衝突する可能性を減らす。その後、生成要求をキャンセルして削除する。
- 最終DB処理で企業プロフィールを削除し、動画企画・台本・入力スナップショット・通知スナップショット・素材ファイル名を匿名化。動画配信を停止する。
- 組織の知識・Bunshin所有者は、従来どおり手動確認で停止する。組織共有のキャラクター素材や法定保持・監査データを一括削除する変更ではない。
- 過去にCOMPLETEDとなった退会への遡及適用は含まない。必要なら別の対象抽出・修復処理を行う。

主なファイル: `packages/database/src/account-deletion-media.ts`、`packages/database/src/index.ts`、`packages/application/src/account-deletion-execution.ts`、`apps/web/src/http/account-deletion-operations.ts`。

### 管理設定

- Runwayを提供準備中と表示し、新規登録・利用開始を止める。既存設定の停止操作は残す。
- 独自ドメインは準備中・停止中の登録に限定し、未実装の公開機能を「確認済み」「利用中」にできないようにする。既存URLを案内する。

## 検証

検証結果はPR本文に記録する。重点項目は未対応動画の黙った代替出力防止、退会のリース・所有者検証、Storage失敗時の再試行、ページ途中での完了防止。

DBスキーマ変更・migrationはなし。本番の削除実行モードを変更する作業は含まない。本番実データの削除、実機でのLINE受信・再生はこの変更の検証では実行しない。

## 続けて実装する項目

今回の変更で以下が完成したとは扱わない。

1. 写真とシーンの対応付け、権利確認、写真を利用した動画合成。
2. 音声合成、時間調整、原価・再試行、動画への音声合成。
3. 保存写真の再利用許可と日次自動生成への適用。
4. 運営者動画配信へのLINE動画添付。
5. 独自ドメインの検証・ホスティング・ホストからサービスへの解決。
6. 決済サービスの選定と有料契約の自動化。既存の手動請求は維持。
7. 新規登録から初回・翌日受信、停止・再開までのスマートフォン通し検証。

提供準備中の選択肢は、上記処理と回帰テスト・実出力検証が揃った段階で再公開する。
