# 実践プログラム 支援方針・目標画面 実装報告

## 管理者ができること

- プログラムごとに提供可能な「企画だけ」「作り方つき」「完成品」を設定
- 最初に選ばれる支援方法を設定
- 参加者自身による支援方法選択の可否を設定
- 小学生でも理解しやすい案内文を設定
- 行動、見てもらえた結果、仕事につながった結果の目標候補を追加

## 参加者ができること

- 参加中のプログラムを確認
- 許可された支援方法から、自分が欲しい形を選択
- 運営者へ伝えたい任意メモを保存
- サービスが用意した候補から目標値と期限を設定
- 現在の目標を確認

## セキュリティ

- 管理画面はSERVICE_OWNER／SERVICE_ADMINだけが利用可能
- 参加者画面は同じサービスのACTIVE Membership本人だけが利用可能
- 希望・目標は本人のEnrollmentとMembershipへ限定
- 別Workspace、別Service、別参加者のResource IDを指定しても取得・更新しない
- POSTはSame OriginとJSONを必須にする

## 対象外

- 市場成果の自動取得
- 目標達成のAI自動判定
- 課金、Checkout、報酬計算
