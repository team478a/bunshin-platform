# 占いのシネマティック演出

タロット召喚は、既存の鑑定リクエストの表示だけを担当する。待機中は装飾用の裏向きカードを表示し、サーバーの応答から確定済みカードを受け取って表返す。スキップは演出を終了し、抽選、生成、購入や同意の処理には影響しない。表示設定は既存の占いデザインに追加し、未設定のサービスでは従来表示を使う。

カード表面は Pamela Colman Smith が描いた1909年版の [公開ドメイン WebP 画像](https://tarostarot.com/tarot-card-data) を同梱する。カード裏面と星空は CSS で描く。キャラクター画像と鑑定の文言は既存設定を使用する。

## 月の門

深層鑑定を送信した直後に、既存APIが完了した深層鑑定データを返した場合、カードの反転に続けて月の門とキャラクターの登場を再生する。生成中・標準結果・再訪・履歴は既存表示を使用する。生成の待機や再試行は既存の画面と生成処理が担当する。

演出の有効化とスキップは既存のカード召喚と共通。登録済みの深層鑑定キャラクター画像を優先し、画像の失敗時は登録済みの表情・アイコンへ切り替える。画像やキャラクターが未登録の場合は名前表示または月の装飾を使う。
