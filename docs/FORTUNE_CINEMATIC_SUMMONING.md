# 占いのシネマティック演出

タロット召喚は、既存の鑑定リクエストの表示だけを担当する。待機中は装飾用の裏向きカードを表示し、サーバーの応答から確定済みカードを受け取って表返す。スキップは演出を終了し、抽選、生成、購入や同意の処理には影響しない。表示設定は既存の占いデザインに追加し、未設定のサービスでは従来表示を使う。

カード表面は Pamela Colman Smith が描いた1909年版の [公開ドメイン WebP 画像](https://tarostarot.com/tarot-card-data) を同梱する。カード裏面と星空は CSS で描く。キャラクター画像と鑑定の文言は既存設定を使用する。

シネマティックでは、通信と重ねて月の紋章が入ったカードの裏面を約1.1秒以上表示する。結果を取得したら約2.2秒かけて反転し、その間に裏面と表面をそれぞれ見せる。先に通信が終わる場合の目安は全体で約3.3秒。カード反転のみ、演出なし、端末のモーション低減には、この追加の待ち時間を適用しない。

## 月の門

深層鑑定を送信した直後に、既存APIが完了した深層鑑定データを返した場合、カードの反転に続けて月の門とキャラクターの登場を再生する。生成中・標準結果・再訪・履歴は既存表示を使用する。生成の待機や再試行は既存の画面と生成処理が担当する。

演出の有効化とスキップは既存のカード召喚と共通。登録済みの深層鑑定キャラクター画像を優先し、画像の失敗時は登録済みの表情・アイコンへ切り替える。画像やキャラクターが未登録の場合は名前表示または月の装飾を使う。

## 神託の書

演出を有効にしたServiceの完了済み深層鑑定を、確定したカードと既存タイトルを表紙にした神託の書として表示する。相談、価値観、承認済みのカード解釈、本文、選択肢、提案は既存と同じ順でテキストとして表示し、追加質問と振り返りは既存の利用条件を使う。

新しく鑑定した場合は、月の門とキャラクターの場面に続けて表紙が開く。スキップ、モーション低減、再訪、履歴詳細からの閲覧では、待たずに結果を表示する。

## 統合と軽量表示

Service別の既存デザイン設定に、従来表示、カード反転のみ、シネマティックの3段階を用意する。未設定と従来の無効値は従来表示、従来の有効値はシネマティックとして読む。保存先は既存設定のままとする。音は再生しない。

キャラクターはServiceに登録した役割を、画面の状態で選ぶ。ホームと無料鑑定の待機は日次役、テーマ選択・ヒアリング・相談の確認・振り返りは案内役、深層鑑定の待機・登場・結果は深層鑑定役を使用する。有効な設定と画像候補がある場合に既存の表示部品を使う。
