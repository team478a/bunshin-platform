# 運用通知センター

## ゴール

管理者が複数画面を巡回せず、日常運用で今すぐ確認すべき異常と対応先を一画面で確認する。

## 集約する通知

- OpenAI設定なし、停止、接続エラー
- AIの日次・月次予算80％超過、上限到達
- AI処理の直近24時間における繰り返し失敗
- LINE設定なし、未確認、全体停止
- LINE配信失敗、自動再試行、自動復旧不能
- LINE以外の定期処理の自動復旧不能
- 停止中の退会処理
- 未対応・緊急の問い合わせ

## 表示ルール

- すぐに対応
- 確認が必要
- 状況を確認

重要な通知から表示し、それぞれ既存の対応画面へ移動できるようにする。

## 設計判断

通知専用データを重複保存せず、各機能の正本データから画面表示時に再計算する。原因が解消されれば通知も消えるため、既読操作による見落としを防ぐ。

## 今後の候補

- 管理者へのメール・LINEによる外部通知
- 通知発生・解消の履歴
- 一定時間継続した障害だけを通知する抑制制御
- CSV出力と定期運用レポート
