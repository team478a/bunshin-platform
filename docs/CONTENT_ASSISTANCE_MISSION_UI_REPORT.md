# 投稿支援レベル 今日の投稿画面 実装報告

## 1. 目的

利用者が今日の投稿案を、必要な詳しさに合わせて「企画」「作り方」「完成版」の順に確認できるようにする。

## 2. 実装内容

- DailyMissionに保存された作成支援レベルを画面へ接続
- 今日の投稿画面へ、やさしい日本語の3択を追加
- 企画ではテーマ、伝え方、理由だけを表示
- 作り方では投稿形式に合わせた手順を表示
- 完成版では既存の投稿文、台本、画像・動画を作るための指示文を表示
- 完成版を選んだ場合だけ、採用後のコピー操作を表示
- 今日の画面上の切替ではSNSの初期設定を変更しない

## 3. 維持した境界

- 既存のMissionContent必須1対1aggregateと保存内容を変更しない
- AIの生成回数やProvider境界を変更しない
- Mission lifecycleと採用・不採用を変更しない
- Workspace / User / Bunshinの認可境界を変更しない

## 4. 次の作業

段階を開いた行動のActivity記録と、SNS別投稿セットのDomain Policyを別PRで実装する。
