# バッジLINE通知 運用確認手順

## 目的

バッジ通知の準備、Job登録、送信停止、再送が矛盾していないことを、サーバーへ接続せず管理画面で確認する。

## 日常確認

管理画面の「LINE設定管理」から「バッジ通知の安全確認」を開く。すべて0件で「問題なし」なら対応不要とする。

- 通知の準備漏れ: Schedulerが次回実行で補完する候補。継続して残る場合は配信設定と同意を確認する。
- 実行予定がない待機通知: SchedulerまたはJob登録の異常。送信を急がず運用担当へ連絡する。
- 自動再送を終了した通知: 原因解消後、理由を記録して管理画面から個別再送する。
- 全体停止中の待機通知: 送信されないことが正常。停止解除前に件数と理由を確認する。
- 停止中グループに残る通知: 送信対象外。グループを再開するまで再送しない。

## 緊急停止確認

1. LINE設定管理で全体停止を有効にし、理由を記録する。
2. 「バッジ通知の安全確認」で全体停止中の待機件数を確認する。
3. Job Workerを通常どおり稼働させ、送信済み件数が増えないことを確認する。
4. 停止理由を解消し、接続確認とQuotaを確認する。
5. SUPER_ADMINが全体停止を解除する。
6. 次回Worker実行後に、待機、失敗、DEAD件数を再確認する。

停止中に配信行やJobを直接削除しない。再開後も送信直前Gateで同意、接続、グループ状態、設定、Quotaを再確認する。
