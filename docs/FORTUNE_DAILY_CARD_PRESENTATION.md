# 今日の占いのカード演出

- サーバーが確定したカードだけをめくる演出に使う。先に決まったカードは再訪・再送でも既存の結果を使い、直接開いた結果や動きを減らす端末設定では演出を伴わない。
- カード固有の絵柄とテーマ別の読み解きの問いを無料の結果画面に表示する。保存済みの鑑定本文・提案および運営者が承認した解釈はそのまま扱う。深層鑑定、AIの呼び出しとプロンプト、抽選、DBには変更を加えない。
- カードの表面は Pamela Colman Smith が描いた1909年版 Rider–Waite–Smith デッキの画像を同梱する。[Taro's Tarot の公開ドメイン画像配布](https://tarostarot.com/tarot-card-data) の WebP をカードコード別に配置した。閲覧時の画像はサービス内から配信する。配布元の鑑定文や意味データは組み込まない。
