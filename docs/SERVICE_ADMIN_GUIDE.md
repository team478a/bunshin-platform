# ワタシワークス サービス管理者マニュアル

サービス管理者は、自分のサービスだけを運用できます。他サービスの参加者、LINE設定、投稿履歴、ナレッジは表示・変更できません。

## 最初に行う設定

サービス管理画面は `/s/{サービスURL}/manage` です。

1. **設定**でサービス名、説明、連絡先、表示色、ロゴ、利用規約・プライバシーポリシーを確認します。
2. **参加者**で運営担当者を追加し、必要な役割だけを付与します。
3. **LINE**で、このサービス用の公式LINEを登録し、接続確認を行います。
4. **ナレッジ**で商品資料、FAQ、PDF、動画URL、Web URLを登録します。
5. **商品パック**または**公式プログラム**で、投稿に使う商品情報、必須表記、禁止表現、キャンペーンを準備します。
6. **投稿承認**の要否を設定し、最初は少人数で試します。

## ナレッジの登録

管理画面の **ナレッジ** から、資料をアップロードまたはURL登録します。

- PDF、テキスト、動画URL、Web URLを扱えます。
- ファイル名だけではなく、何の資料か分かるタイトルと短い説明を付けます。
- 公式情報、FAQ、価格、禁止表現、販売条件は資料を分けて登録すると管理しやすくなります。
- 登録後は抽出・確認の状態を見て、失敗した資料は差し替えます。
- 個人情報、APIキー、契約書の機密部分、顧客リストは登録しません。

## LINE運用

- サービス専用LINEを使う場合は、**LINE**画面からそのサービスの設定だけを登録します。
- Channel Secret、Access Tokenは保存後に平文で再表示されません。元の値は安全な保管先にも残してください。
- 接続確認は、設定値の有無だけではなく、LINE側へ最小限の確認を行います。
- 配信時刻、休止時間、全体停止、配信上限を確認してから有効化します。
- 配信失敗はLINE運用画面または運用通知で確認し、再送は必要なものだけ行います。

### 先行運用を開始・復旧する順番

1. サービス管理トップの「開始準備」で、未完了項目を確認します。
2. 専用LINEでは、ルーティングを「専用LINE」にし、接続確認後に設定を有効化します。
3. 「標準リッチメニューを公開」を実行し、現在のLINE設定にメニューを紐付けます。
4. OpenAI、ナレッジ、商品・キャンペーン、投稿URLの準備完了を確認します。
5. テスト利用者1名で登録、文章生成、LINE表示を確認してから対象者を増やします。

LINEの認証情報を変更した場合は、まず全体停止し、新しい設定として保存して接続確認・有効化・標準リッチメニューの再公開を順に行います。古い設定への自動フォールバックは行いません。最後に「開始準備」を再確認してください。

## コンテンツ・投稿の運用

- **公式プログラム**で参加者の目標・活動内容を管理します。
- **キャンペーン**で期間、投稿テーマ、必須表記、禁止表現、承認ルールを設定します。
- **投稿承認**では、利用者の投稿案を確認し、承認・差し戻し・却下を記録します。
- **投稿URL**では、参加者ごとの外部成果計測URLを設定できます。URLのクリック・報酬・購入者情報は扱いません。
- URLは商品・キャンペーン・参加者に応じて自動選択されます。未設定のまま商品投稿を許可しないことを推奨します。

## 画像・動画の運用

- **画像運用**では、生成申請の状態、利用可能な回数、結果を確認します。
- **動画運用**では、素材、企画、場面、レンダリング、配信の順に進みます。
- 完成動画は配信前に確認し、問題があれば停止して差し替えます。
- 配信状況はCSVとして出力できます。停止・差し替えの履歴も残ります。
- 生成回数や利用枠はサービスの契約・機能設定を超えないよう確認します。

## 日次・週次の確認

### 毎日

- 運用通知に「すぐに対応」がないか
- LINE配信失敗、画像・動画の失敗、投稿承認待ちがないか
- 公開中キャンペーンの必須表記・URLに誤りがないか

### 毎週

- 投稿数、採用率、コピー率、投稿完了率を確認
- 参加者からの不採用理由・フィードバックを確認
- FAQや商品情報に古い内容がないか確認
- 期限が近い紹介URL、キャンペーン、配信設定を確認

## 権限の考え方

- 管理者は必要最小限にします。
- コンテンツ担当者には、参加者全体の権限変更やLINEの秘密情報変更を与えません。
- 参加者には、他参加者の紹介URL・通常投稿・個人メモリーは見せません。
- 操作履歴は監査ログに残ります。問題時は削除せず、まず停止して記録を確認します。
