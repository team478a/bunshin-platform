# 千ノ国メディアの参加先・画像用プロンプト修正

## 調査

ユーザー提供画像では「Discord参加」とDiscord画面が生成されていた。参加窓口の正しい仕様は公式LINE。調査時点のコードにDiscordの固定案内は見つからず、サービス固有の表記ルールと外部画像AIへコピーするプロンプトに、参加先と画面表現の制約が不足していた。本番の対象原稿・生成ログは未確認のため、その画像が生成された経路の断定はしない。

## 変更と判断

- `service-content-terminology.ts`: 千ノ国メディアだけに公式LINE参加ルールを追加。既存の生成知識経路（通常生成、週間計画、別案、フォールバック）へ渡す。生成結果の文字列補正は既存の適用経路を利用する。
- `daily-mission-content.tsx`: コピー時に原稿・見出し・場面・投稿文を補正し、画像用指示の末尾に参加先とDiscord画面禁止、未提供のURL・QRコード・手順・所要時間の創作禁止を追加。
- サービスの画像作成ガイドと採用後のコピー導線からサービス識別子を渡す。個人利用と他サービスは変更しない。
- Discord URLは文字列置換より先に除去し、架空のLINE URLへ置換しない。提供済みのLINE URLは維持する。
- 保存済み原稿と別案はコピー時のみ補正し、DBを書き換えない。Provider/Coreの境界、権限判定、コピー認可、品質ゲートは変更しない。DB migrationは不要。

## 検証

表記ルール、既存URL除去、新しい参加案内、画像・スライドのコピー、選択済み別案、非破壊補正、他サービスへの非適用を自動テストする。既存の生成・フォールバック・境界テスト、型検査、lint、format、buildも確認する。実行結果はPRに記載する。

## 未解決・本番確認条件

実装・自動検証と本番反映を区別する。本番DB変更、デプロイ、LINE送信、実APIでの画像生成はこの作業では行わない。既に生成した画像は自動修正されないため、本番反映を確認後、新しい指示をコピーして再生成する必要がある。外部画像AIの指示遵守は自動テストだけでは保証できないため、公式LINE表記とDiscord画面がないことを生成画像でも確認する。
