# 活動継続 J3-B LINE復帰通知 実装報告

## 完成した範囲

- 7日以上活動がない利用者へ、既存Daily Mission通知を低優先の復帰通知として送る。
- 本人が通知とリマインダーを許可している場合だけ候補にする。
- 同じ利用者・分身への復帰通知は7日間隔を空ける。
- Provider呼出し直前に、現在の同意、一時停止、曜日、通知休止時間を再確認する。
- 全体停止、月間上限、低優先通知停止、LINE接続状態、短期署名付きDeep Linkを既存基盤から再利用する。

## 送らない条件

- 通知またはリマインダーが無効
- 同意がない
- 一時停止中、対象外の曜日、通知休止時間内
- Workspace、User、Bunshin、Membershipが無効
- 直近7日以内に復帰通知を予約または送信済み
- LINE全体停止、Quota停止、接続先不明

判定できない場合は安全側に倒し、送信しない。Webの今日やることと活動記録は引き続き利用できる。
