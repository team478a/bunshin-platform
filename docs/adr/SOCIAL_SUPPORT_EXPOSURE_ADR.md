# SNS支援の表示・詳細閲覧の到達記録

2026-11-02 / main 01b4e321（#1436）

既存Interventionの採用・完了・見送り時刻から、画面表示・詳細を開いた事実は再構築できない。新しい推薦/イベント台帳を作らず、既存InterventionにfirstDisplayedAt / firstDetailsViewedAtのnullable列だけを追加する。新規保存が必要な提案履歴という元指示の範囲で本migrationを作る。過去値を推測で埋めない。

画面の支援カードが可視領域に入ったとき、詳細を本人が開いたときに、既存本人向けAPI境界を通した記録要求を送る。GETは読み取り専用のまま。日時はサーバー受信時刻で、実際に読んだことの証明ではない。再送・並行要求はBunshinロックと初回値の保持で冪等化する。詳細要求を先に受けた場合は表示時刻も同時に記録する。採用・完了・見送り状態を変更しない。

記録は本人・所属・同意・Bunshin・ACTIVE SOCIALと現在の機能権限を再検証する。他OEM/Bunshinを混ぜない。外部AgentやSNSは呼ばず、送信payloadはsupportIdと種別だけ。失敗で支援操作を止めず、ログに失敗を残す。再読込で再試行可能とする。

新規支援の既存definitionSnapshotへ計測版だけを保存する。旧支援のnullを未閲覧の0と断定しない。既存Support観測Adapterの認可・原本取得を再利用し、表示/詳細の提供期間cohortを別sectionで既存Overviewへ投影する。既存の支援採用/完了集計の定義は変えない。欠測・少数セル・打切りは既存共通処理で非表示。指標は届いた初回記録であり、全閲覧や実利用・負担軽減を捕捉した率ではない。

SNS固有の計測契約はSOCIAL、保存はDB、表示トリガーはWebへ置く。共通Applicationへ固定SNS指標を追加しない。本番適用・デプロイ、設定開始/完了の外部連携状態、人数体験権限は本作業外。
