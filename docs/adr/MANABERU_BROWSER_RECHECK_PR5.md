# 開発用操作教材の再検証と版管理

再検証は既存ジョブで実行する。学習者の画面相違の報告は操作対象・版への参照だけをキューへ渡す。定期実行は既存の証拠から対象を拾い、元の受講範囲と現在の要望を実行前後に検証する。共有教材に利用者の画面や相談内容を取り込まない。

実行結果の比較には操作、画面の導線、操作要素のアクセシビリティ情報を使う。スクリーンショットの生バイト、座標、実行日時を比較に含めない。すべての操作と成功条件の検証を通過した場合にだけ版を追加する。初期版には比較値がないため、初回の再検証で比較可能な版を作る。

現行版は同一 Program と端末向けに保存された最新の版とする。旧版を復旧する場合は既存の画像と説明を新しい版として保存する。再検証ジョブは依頼時の版を参照し、対象版が切り替わると処理を終了する。教材は開発用の検証画面に限定する。
