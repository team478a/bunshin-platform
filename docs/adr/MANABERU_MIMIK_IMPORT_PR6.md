# 人が記録した操作教材の取り込み

Mimik Desktop v1.2.0 の `.mimik` バンドル v1 のうち、ガイド名、説明、手順の順序と説明、スクリーンショットを既存の教材と手順へ投影する。画像はデコードして WebP として保存する。元ファイル、操作対象のセレクタ、URL、入力値、読み上げ原本は保持しない。記録の再生や外部サイトへの接続は行わない。

取り込みは開発環境の既存操作教材ライブラリから利用する。保存先は現在の Workspace と本人の所属に紐付ける。内容から再計算したハッシュで同じ教材の登録をまとめる。他の受講者への公開や自動再検証には接続しない。

記録由来の教材は撮影画像を1枚ずつ表示する。システムが操作を検証した教材と区別できるよう、画面には取り込み日と操作の検証状態を表示する。
