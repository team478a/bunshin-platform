# 検証用ブラウザのモデル選択

PR #1626 の追加。開発用 CLI の明示的なモデル探索だけを対象にする。

- ワーカーが実画面で選択肢を確認した場合に限り、Web の専用内部エンドポイントにジョブ ID とリース所有者を送る。Web は開発環境と設定済み Workspace、現在のリース、依頼者の所属を照合し、登録済みの合成候補だけを使う。
- 既存の Google 学習アダプターと Provider 利用枠、単価表、AI 利用記録を再利用する。ジョブ ID で一度だけの予約とし、原価が不明な場合は予約を保持する。
- モデルは候補 ID を返す。ワーカーが現在の候補に含まれることを確認して Playwright で実行し、既存の成功条件を確かめる。保存済みレシピの再実行ではモデルを呼ばない。
