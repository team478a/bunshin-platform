# 占いの基本プロフィールと相談プロフィール

調査基準は main の `0c9a3b81`。既存の年齢確認は占い参加者、相談プロフィールは同じ参加者行の相談専用フィールドが正本。共通の利用者情報や登録プロフィールは他サービスでも使用するため、占いの入力先には使わない。

[従来のADR](FORTUNE_PERSONAL_GUIDANCE_V1.md) では、生年月日の取得を新しい占術の導入まで見送っていた。Phase 1では任意の基本プロフィールとして、利用目的の説明と本人の同意が揃った場合のみ保存する。タロットの生成には送らない。出生地・時刻などは、必要になった占術ごとに目的・同意・参照範囲を定める。

- 基本プロフィールは、年齢確認済みの占い参加者を鍵とした専用テーブルに保存する。本人の操作のみが対象で、管理画面・CSV・イベント・鑑定生成から参照しない。
- 基本プロフィールと相談プロフィールの同意は独立する。基本プロフィールは相談履歴の保持期限と独立し、本人による削除・撤回、会員資格の取消、参加者削除まで保持する。
- スキップ・削除後の初回案内制御には、回答値・同意と別に完了時刻を保持する。再加入時に以前の入力値を復元しない。
- 会員の取消とプロフィール保存は同一の会員行で直列化する。退会・運営による取消で共通会員が取消状態に移ると、同じトランザクションで基本プロフィールを削除する。アカウント削除時は利用者行を更新してから、全参加サービスの基本プロフィールを同じトランザクションで削除する。占い参加者の削除時は外部キーによって連鎖削除する。
- 生年月日はDBの `DATE` に保存し、APIは `YYYY-MM-DD` を返す。18歳判定は日本の日付を使う。非うるう年の2月29日生まれは3月1日から入力できる。未入力時は既存の年齢確認を利用する。
- 新規保存はサービス別の設定が有効な場合のみ許可する。本人による閲覧と撤回は設定を停止した後も利用できる。
