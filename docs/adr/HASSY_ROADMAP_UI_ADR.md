# ADR: 成長ロードマップの会員ホーム表示

作成日: 2026-11-02
Status: Accepted for Phase 1-B4 implementation.

- 投稿パートナーホームの「その他のメニュー」に本人限定の成長ロードマップを追加する。既存90日計画とは区別し、「今日やること」を優先する。
- 初期表示で集計しない。「成長ロードマップを見る」を押したときだけ既存member-roadmap / member-usage APIを順次GETする。同時1件の既存guardを回避・緩和しない。
- 2つのAPIの公開項目だけをvalidationして表示する。別時点の取得であることを明示し、片方の失敗時は古い進捗も消して再確認を案内する。自動poll / 自動retry、永続client cacheは使わない。切替・unmount時はabortし、前の応答を表示しない。
- 達成済み・利用可能・準備中と、不明な達成証拠を区別する。採用数・本人の投稿完了報告・活動日数を分け、SNS上の公開確認とはしない。有効紹介・特典は未接続なので「集計準備中」とし0件を捏造しない。
- 次の候補はAPIの最大1件を表示する。初版の操作リンクはFIRST_DECISIONから同ホームの投稿案へ戻るアンカーだけ。表示時点の可否は実行権限を付与しない。未接続のガイド・外部操作・他BunshinへのURLを推測しない。
- UIは白背景、Noto Sans JPを先頭とするフォント、44px以上の操作領域、文字による状態表示とprogressを使う。スマホで実コンポーネントを合成APIで検証する。本番認証・DBの通し検証とは区別する。
- Application / Database / API契約 / schema / migration / 特典 / Flag / Providerは変更しない。UI表示だけを紹介条件や既存基本機能のgateにしない。
