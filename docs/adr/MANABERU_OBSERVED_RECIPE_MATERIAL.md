# カタログレシピから画像付き教材を生成する

既存の `material` ジョブで、練習用メモと開発用カタログの検証済みレシピを扱う。レシピの版に対応する画面から得た操作証拠を再利用し、画像が見つからない場合は対応する画面をモデルなしで再実行する。ステップ ID に基づく画像加工・説明生成、教材の重複防止、本人の閲覧権限、動画ジョブは既存の処理を使う。

カタログ向けの目的・準備・実践課題は、管理対象の検証画面と成功条件に合わせる。教材の Web 表示と動画化は、既存の開発用教材画面から行う。

モバイル画像の強調位置はブラウザの実表示領域を基準に計算する。旧座標で記録したカタログの証拠は、新しい教材を生成する際に再取得する。
