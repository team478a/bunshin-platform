# 深層鑑定は同じ日のタロット結果を使う

Phase 3 PR-3では本人が確認した今回の相談を、既存Readingの生成入力として扱う。既存のタロット抽選、標準解釈、AI枠、非同期ジョブを再利用する。Serviceの案内設定で深層鑑定を有効化でき、既定はOFF。鑑定前のヒアリングと個別化が有効なServiceで、確認済み項目がある場合に適用する。

本人が確認した相談内容と大切なことは入力から組み立て、カードの視点には承認済み標準解釈を使う。AIは状況に当てはめた視点、選択肢、今日の一歩と理由、設定に応じた振り返りを生成する。成立した深層鑑定は既存のReadingと同じ保存期間・削除経路で扱い、結果に含まれる相談内容を次回の個別化には渡さない。

確認済み項目は生成待ちの間だけReading内に保持する。生成成功・失敗・復旧・鑑定削除で消去し、プロフィールの変更・同意撤回・退会でも生成待ちデータを消去する。既存の保存済み標準結果へのフォールバックは、同じカードと正逆を維持する。
