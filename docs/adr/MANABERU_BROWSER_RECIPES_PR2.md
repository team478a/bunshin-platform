# マナベルスタイルの操作探索と検証済みレシピ

基点は PR #1625 マージ後の main `3c53020d`。

- 探索時は実画面で操作できる候補だけに絞る。候補 ID の選択と Playwright の操作を分離し、実行側がリポジトリ管理の操作と照合する。開始画面、合成入力、成功条件はワーカーが管理する。
- 成功条件を実際に観測した計画だけを PostgreSQL に登録する。レシピは Workspace と依頼者に束縛する。保存済み計画はリプレイ時に再検証し、候補選択を呼ばない。
- 専用ジョブ種別と既存リースを再利用する。レシピ登録とジョブ完了を同じ DB トランザクションに置き、期限切れの試行からレシピが登録されることを防ぐ。
- 対象は PR-1 の開発専用検証画面。Stagehand とモデル Provider の検証結果、稼働範囲は実装報告に記録する。
