# 占い収益化実証 Phase 1

日付 2026-11-22

既存の無料公開方針に、単発の深層パーソナル鑑定の購入と案内を加える。無料の今日の占い、履歴、設定、同意撤回は購入から独立する。最初の実証対象は watashi-fortune。商品未設定時は販売しない。ほかの既存 Service の無料試験は、商品が設定されるまで既存の適用条件に従う。

ServiceCommercialSetting は契約や登録枠を扱う。ProgramOffering と ProgramPurchase は期間付き Enrollment の提供・取消に紐づく。単発鑑定は Service 別の商品設定と購入記録を持ち、既存 Stripe 接続、Checkout、署名検証と PaymentWebhookEvent を使う。注文時の価格、商品名、提供条件、追加質問回数を購入時点の値として記録する。

購入を1件の Reading に予約し、深層結果の保存と同時に利用を確定する。生成失敗、削除、同意撤回では鑑定を再提供できる状態を確認する。日本時間1日1件の Reading を維持し、カードと正逆を変更しない。全額返金後は未提供分と追加質問を停止し、提供済みの結果は既存の履歴・削除ルールで扱う。部分返金額は累計で記録する。返金実行は Stripe 側の運営手順に従う。

本番での販売有効化、法定表示の公開、決済設定の変更、実請求は別途承認する。Stripe テストモードでは署名付きイベントの再送・返金・生成失敗を確認する。
