# 占いの利用者プロフィールと継続利用

調査基準は `main` の `b98bbccd`。

| 調査対象         | 既存の実装と対応する差分                                                                                                                           |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 個別化           | 本人の直近7件と選択式評価、本人が同じサービスで選んだBunshinの目的・人格と関連MemoryをAI生成時に参照する。本人の関心、質問、文体の保存を追加する。 |
| プロフィール     | `FortuneParticipant` に共通会員への参照、年齢確認、選択Bunshinがある。関心等はこの行でサービスごとに保存する。                                     |
| Memoryと履歴     | 生成Repositoryが取得し、Readingへ参照IDを保存する。プロフィールをBunshin Memoryへ転記しない。                                                      |
| 鑑定・保存・評価 | 承認済み標準解釈、1日1回のタロット抽選、構造化AI出力、標準結果へのフォールバック、任意の選択式評価がある。共通Jobによる再試行は既定OFF。           |
| 過去データ       | 本人とサービスの境界があり、閲覧期限後は日次削除する。新しい個別化では明示同意と保存期限を適用する。                                               |
| 利用者画面       | 今日の占い、履歴、結果、設定、マニュアルがある。初回ヒアリングと設定での編集を追加する。                                                           |
| 運営機能         | パッケージ導入・公開、標準解釈、週次LINE、登録・継続ファネル、評価・品質、AI使用量・原価がある。                                                   |
| 本番確認         | 承認済み解釈、公開、利用文書、AI接続と予算、LINE接続と同意、Cronは環境ごとに確認する。                                                             |

ヒアリングはサービス別に既定OFFとし、年齢確認後に表示する。本人の同意時だけ自由入力を保存する。スキップ・撤回は入力を空にして完了時刻を保持する。生年月日は必要な占術が導入されるまでは収集しない。

既存のタロットとAI生成を拡張する。自由入力からの推定は本人の事実として書き戻さない。振り返りは元の鑑定と保存期限に紐づける。占術追加は承認済みの計算・解釈を入口とし、有料提供は本人の希望とサービス設定を入口とする。
