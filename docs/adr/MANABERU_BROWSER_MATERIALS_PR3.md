# 検証済みレシピから生成する画像付き教材

基点は PR #1626 マージ後の main `308d91fb`。

- 検証済みレシピの操作証拠を、同じ手順 ID と並びで教材化する。ワーカーの既存証拠を優先し、保存先に画像がない場合はレシピを新規セッションで再検証する。
- 説明は構造化された実行命令から生成する。Sharp で実画面画像を WebP に変換し、観測できた操作対象には枠と拡大画像を付ける。Mimik のステップと注釈の考え方を参照する。
- 教材とステップ画像は既存の PostgreSQL に保持する。レシピに由来する所有者と Workspace の境界を引き継ぎ、生成版とレシピの組で重複を防ぐ。既存ワーカーのジョブ完了と同じトランザクションで保存する。
- 検証用の合成教材のみ、開発環境の認証済みページで検索・表示する。受講者の自由希望、Program、LINE 配信、共通教材の公開範囲は PR-4 で接続する。
