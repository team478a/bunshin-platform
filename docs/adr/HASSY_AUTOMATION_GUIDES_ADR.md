# ハッシーの投稿準備・外部自動化ガイド

2026-11-02 / main bf540625（#1435）

既存のHASSY profile selectorと本人向け「その他のメニュー」を再利用し、静的な投稿準備・Zapier利用ガイドを提供する。共通Domain/Application、SNS共通catalogにブランド固有のサービス名・手順を固定しない。

ガイドを読む・固定の指示文をコピーするだけで、アカウント接続、投稿、AI生成、設定変更、外部送信は実行しない。本人の投稿本文・企業情報・Memory・Tokenを指示文へ自動挿入しない。コピーできない場合は選択して手動コピーする。クリップボード成功を連携完了や支援実利用として保存しない。

Zapierは公式文書で確認できたtrigger/action、テスト時も実操作が起こること、プラン別の上限とタスクを案内する。ハッシー専用Zapierアプリ、API、OAuth、MCPの存在・商用可否を推測しない。料金や無料枠の数値を固定せず公式ページへ案内する。ハッシーは外部登録なしで通常利用できる。

MUSEは公式サービスが特定できていないため、確認前に登録URL・機能・連携手順を実装しない。ユーザーへ公式URLを確認中。紹介人数による権限や体験特典は付与しない。ガイド閲覧をロードマップ達成として捏造せず、既存の進捗定義も変更しない。

新規DB・イベント台帳・Job・Flag・有料処理は追加しない。本番設定とデプロイは本作業外。画面の接続・サービス分離・コピー成功/失敗・スマホ操作を検証する。
