# 開発用カタログの実モデル検証を計測する

既存ジョブと Google Provider の予約・AI 利用記録を、ジョブとステップの既存キーで照合する。対象は Development のカタログ探索ジョブで、同一条件の再利用ジョブも含む。新しい原価台帳を作らず、ブラウザワーカーの読み取りコマンドから JSON を得る。

承認済み開発環境で探索ジョブを実行し、同じ端末で異なるリクエスト ID を指定して再利用する。各ジョブの出力に含まれる ID を指定する。

```sh
pnpm --filter @bunshin/browser-worker start report-observed-model "$WORKSPACE_ID" "$ACTOR_ID" "$JOB_ID"
```

実行中のジョブ、未精算の予約、記録の欠落がある場合は、合計原価を未確定として扱う。出力する金額は既存単価による USD マイクロドルの推計値で、請求明細や VPS・ストレージ費用は含まない。
