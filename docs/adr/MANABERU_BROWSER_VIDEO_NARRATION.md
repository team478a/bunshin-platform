# 画像付き教材の日本語ナレーション

開発用ブラウザワーカーで、既存の手順説明を Open JTalk で読み上げる。外部 API への送信や課金は発生しない。音声の実測時間で、手順ごとに映像・字幕・チャプターを延長する。作業ファイルはワーカーの一時ディレクトリに置き、処理終了時に削除する。

音声付き出力は動画形式 v2 とし、元の教材版と認可を共有する。すでに保存された v1 と移行前の待機ジョブを保持し、v2 の準備ができるまで v1 を再生できるようにする。DB の既存の版キー、非公開配信、作業キューを再利用する。

2026-11-26 追記。動画形式 v3 は MMDAgent Project Team の HTS Voice「Mei (Normal)」を使い、話速を標準の 0.90 倍にし、声の高さを標準より半音 1.5 個分下げる。音声モデルとライセンスを固定し、出典を教材ページと MP4 に表示する。v1 と v2 はそのまま再生でき、女性ナレーション付き動画の依頼時に v3 を生成する。VPS へ配置する場合は v3 対応のワーカーを先に更新する。 [音声モデルのライセンス](https://github.com/r9y9/pyopenjtalk/blob/v0.4.1/pyopenjtalk/htsvoice/LICENSE_mei_normal.htsvoice)

テスト運用では、検証済み操作教材で志織（v4）と大智（v5）を選べる。動画版キーで声の選択と成果物を教材に紐づけ、同じ教材・同じ声を再利用する。Azure Speech には手順文だけを送る。人が取り込んだ記録はローカル音声を使う。従来の版と配信権限を維持する。クレジットや音声提供元は動画画面と MP4 に記録する。

録画の取り込みと本番公開の検証は別の作業とする。

## Azure Speech の管理画面設定

設定を環境ごとに1件保持し、対象の Workspace・リージョン・暗号化した接続キーをプラットフォームの管理者が登録する。接続確認は音声一覧だけを取得する。試聴は管理者が固定文を2回だけ合成して保存し、受講者には保存した音声を配信する。

受講者が依頼した動画では、既存ワーカー認証を使って Web 側でジョブのリースと教材の閲覧権限を再確認する。Web が登録済みのキーと DB の手順文から音声を生成する。ワーカーには音声だけを返す。環境分離と既存の利用記録を使用する。
