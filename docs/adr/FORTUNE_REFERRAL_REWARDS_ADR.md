# 占いの友だち紹介と特典

## 現状と再利用

| 区分               | 確認結果                                                                                                                                       |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| そのまま再利用     | 会員ごとの紹介コード発行、URL・QR・LINEとSNS向け文面の共有、公開サービスへのリダイレクト、サービス別のクリック・紹介登録記録、既存の管理権限。 |
| 設定変更で利用可能 | サービスの公開範囲、参加方式、紹介元の記録。占いテンプレートの紹介初期値は無効。公開切り替えは運営承認後に行う。                               |
| 接続実装が必要     | 占いホームと既存紹介画面の接続、サービス別の特典ルール・クレジット台帳への占い成果の接続、サービス別の交換設定。                               |
| 新規実装が必要     | FORTUNEでの最初の無料鑑定と決済確定済みの購入の成果判定、鑑定への特典交換と失敗時の返却。                                                      |

## PR1 の判断

公開かつ公開申込が可能で紹介が有効なサービスで、占いホームから既存の紹介画面へ移動できるようにする。占い管理画面から共通設定の「参加方法・公開条件」を開けるようにする。「紹介元を記録する」の変更には既存の設定監査ログが適用される。紹介に関する表示は本人の紹介件数・状態と日付に限定する。確定済み紹介の集計には既存の審査状態を使う。参加件数は共通の紹介登録記録の集計であり、報酬資格には初回会員登録の証跡を使う。紹介コードとURLの発行、クリック計測、参加処理には既存のAPIと認可が適用される。

## 後続の判断

PR2で初回無料鑑定の完了を優先し、成果と資格を確認した上でサービス別のルールに従って特典を付与する。有料鑑定は署名検証済み決済を成果に使い、返金を資格の見直しに反映する。PR3の交換原資はService Creditとし、Workspace共通ポイントとは台帳を分ける。最初の交換先は鑑定への追加質問を候補とし、既存の利用権限と生成フローとの整合を検証する。

## PR2 の判断

新規登録の監査証跡と運営者の審査・確定を既存の共通処理から利用する。占いの成果判定は FORTUNE に置く。無料鑑定の成果は、無料の結果を初めて表示した時点で鑑定の閲覧時刻に記録する。審査に使うのは閲覧日数だけとし、鑑定本文は取得しない。決済は確定済みで返金を観測していない有料注文を数える。

確認済み紹介向けの共通マイルストーンでサービス別クレジットを付与する。サービス単位で付与先、数量、期限、月間上限を設定する。付与条件は初回無料鑑定を優先する。有料購入は審査の条件とし、返金で条件を満たさなくなった紹介の確定と未使用特典を取り消す。稼働環境への切替と実際の特典付与は運営承認後に行う。

判定はPR2導入後に記録された無料鑑定の閲覧と、返金のない本番モードの確定済み購入を対象にする。無料鑑定の既存結果をさかのぼって推定しない。運営画面では審査前に登録対象期間を指定できる。返金後も必要購入回数に達していれば確定を維持する。

## PR3 の判断

サービス別クレジットの初回交換先は、本人が閲覧できる鑑定への追加質問とする。無料鑑定でも、既存のAI利用条件とプロフィール同意を満たせば利用できる。購入済み鑑定は購入時の追加質問枠を優先し、全額返金済みの有料鑑定は交換対象から外す。カード抽選の仕組みは従来どおりとする。

運営者がサービス内の名称、必要数、鑑定ごとの交換上限、利用の有効・無効を設定する。クレジットの有効期限は付与ごとの既存設定に従う。初期値は停止とする。運営設定と利用者の消費は、それぞれ既存の監査ログとサービス別クレジット台帳に残す。

質問の処理中は追加質問の既存レコードで必要数を一時確保し、回答の保存と消費を同じDBトランザクションで確定する。生成失敗・利用条件の変更・既存の処理中表示期限超過・鑑定削除で確保を解除する。消費確定時にも期限と返金による特典取消を確認する。会員の再送は同じ回答・処理状況を返す。通常の追加質問は従来の件数契約を維持する。
