# 占いの友だち紹介と特典

## 現状と再利用

| 区分               | 確認結果                                                                                                                                       |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| そのまま再利用     | 会員ごとの紹介コード発行、URL・QR・LINEとSNS向け文面の共有、公開サービスへのリダイレクト、サービス別のクリック・紹介登録記録、既存の管理権限。 |
| 設定変更で利用可能 | サービスの公開範囲、参加方式、紹介元の記録。占いテンプレートの紹介初期値は無効。公開切り替えは運営承認後に行う。                               |
| 接続実装が必要     | 占いホームと既存紹介画面の接続、サービス別の特典ルール・クレジット台帳への占い成果の接続、サービス別の交換設定。                               |
| 新規実装が必要     | FORTUNEでの最初の無料鑑定と決済確定済みの購入の成果判定、鑑定への特典交換と失敗時の返却。                                                      |

## PR1 の判断

公開かつ公開申込が可能で紹介が有効なサービスで、占いホームから既存の紹介画面へ移動できるようにする。占い管理画面から共通設定の「参加方法・公開条件」を開けるようにする。「紹介元を記録する」の変更には既存の設定監査ログが適用される。紹介に関する表示は本人の紹介件数・状態と日付に限定する。確定済み紹介の集計には既存の審査状態を使う。参加件数は共通の紹介登録記録の集計であり、報酬資格には初回会員登録の証跡を使う。紹介コードとURLの発行、クリック計測、参加処理には既存のAPIと認可が適用される。

## 後続の判断

PR2で初回無料鑑定の完了を優先し、成果と資格を確認した上でサービス別のルールに従って特典を付与する。有料鑑定は署名検証済み決済を成果に使い、返金を資格の見直しに反映する。PR3の交換原資はService Creditとし、Workspace共通ポイントとは台帳を分ける。最初の交換先は鑑定への追加質問を候補とし、既存の利用権限と生成フローとの整合を検証する。
