# 占いカードの追加と絵柄の差し替え

標準の78枚をすべてのサービスの初期デッキとする。運営者はサービス単位で標準カードの絵柄を差し替え、独自カードを追加できる。独自カードを抽選対象にするには、正位置・逆位置と3テーマを組み合わせた6件の解釈を、既存と同じ検査と承認で確定する。

カード設定と解釈を同じ知識バージョンに保存する。公開済みのバージョンを更新したときは新しい版を作り、鑑定は使用した版を参照する。独自カードを抽選対象から外しても既存鑑定の表示は継続する。標準解釈の再インポートでは独自カードとその解釈を引き継ぐ。

抽選には引き続きサーバー側の暗号学的乱数を使う。抽選に用いたデッキの知識バージョンを結果へ記録し、1サービス・1利用者・日本時間の1日につき1枚という制約を維持する。

登録画像は運営者が管理する公開HTTPSの画像URLを、ブラウザーから参照する。過去の画像を保存するには差し替えごとに別URLを登録する。既存の標準絵柄は同梱のWebPを使う。
