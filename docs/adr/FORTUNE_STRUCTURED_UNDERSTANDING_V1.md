# 確認できる相談内容と任意の継続保存

Phase 3 PR-2では、PR-1の回答と自由相談を、入力元と本人確認状態のある項目に整理する。明示された内容だけを本人申告（CONFIRMED）とする。未回答はUNKNOWNとし、相談の目的が未回答の場合に限り、本人が選んだテーマから作った整理の候補をINFERREDとして表示する。候補は本人が確認するまで、鑑定入力と継続保存の両方から外す。分類と候補の表示に追加のAI呼び出しは発生しない。

今回の整理は画面内の下書きとして扱う。本人が選んだ確認済みの項目だけを、個別化の同意が有効な間、既存のFortuneParticipantに保存できる。保存内容は本人設定から確認・訂正・削除できる。Serviceの保存期限とプロフィール同意の有効期間の両方を適用し、プロフィールの訂正・削除、同意撤回、退会では保存した内容を同時に消去する。既存プロフィールと保存内容の版を確認してから書き込み、古い画面からの再保存で消去を取り消さない。

今回の鑑定に使う内容は確認済みの項目を既存の相談入力に整形して渡す。保存内容を次回の鑑定へ読み込む処理や構造化した鑑定出力は後続PRで扱う。
