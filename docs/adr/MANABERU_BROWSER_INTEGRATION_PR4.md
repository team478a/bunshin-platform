# マナベルスタイルの操作教材パイロット

Development の動的学習 Program で操作教材を個別学習要望から案内する。生成対象は自社の操作練習ページのメモプレビューとし、学習要望、認証情報、利用者の入力を Chromium や外部モデルへ渡さない。

共通教材の再利用単位は Workspace、Service、Program、端末、教材リビジョンとする。従来の所有者限定プレビューはレシピへの紐付けでアクセスを検証する。受講者向け教材と画像は既存の受講者認証から判定した範囲で返す。

生成は既存の Development ブラウザワーカーのキューで行う。ジョブは学習要望のリビジョンに結び付け、申請時とワーカー実行時に利用範囲を確認する。既存の LINE 学習返信に Web 教材のリンクを追加する。教材の準備状態を確認できない場合は既存の返信を配信する。
