# 鑑定前の動的ヒアリング

Phase 3 PR-1では、AIが相談に応じて承認済みの質問から次の1問を選ぶ。相談が十分なら終了し、回答者はどの段階でも通常の占いに進める。質問候補から選ぶ方式により、診断や決めつけ、既出質問の繰り返しを出力段階で防ぐ。

既存のService別案内設定に初期OFF、追加質問数（既定3、最大5）、鑑定前のAI呼び出し上限を追加する。同じ参加者の同じ日本日の質問選択を順番と占いServiceの範囲で管理し、Provider Admission、Service・Organization枠、占いの原価記録を使う。設定の変更や鑑定作成後は新規の質問生成を受け付けない。

この段階では質問の選択コードと呼び出し管理用の状態をDBに保存し、前日以前の行は既存の占い保存期限処理で削除する。自由入力と回答は画面内で扱う。本人が「ここまでで占う」を選んだ時だけ、今回の回答を既存の一回限りの相談入力として渡す。既存プロフィールは本人同意と保存期限が有効な場合だけ、重複質問を避ける判断に利用する。構造化理解の確認と継続保存はPR-2以降で扱う。
