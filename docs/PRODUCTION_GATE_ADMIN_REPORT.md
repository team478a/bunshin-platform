# Production Gate管理画面 実装報告

## 1. 調査結果

運用設定画面には、AI、LINE、LINEメニュー、暗号化鍵、Cron、画像保存先の自動確認が既に存在した。一方、100人検証開始に必要な法務、退会、Migration、backup復元、実端末smoke、最終承認は同じ画面で整理されていなかった。

ロードマップには、既に完了したLINE Login、Mission作成支援、UI、トレンド表示・集計を未実装とする古い記述が残っていた。

## 2. 変更内容

- 運用設定トップへ「100人検証を始める前の確認」を追加した。
- 自動確認と、人が実行して記録する確認を分離した。
- 利用規約・プライバシー両方の公開状態を自動確認する。
- Auth管理設定と退会実行モードを自動確認する。
- Production以外の環境を開始可能と表示しない。
- 操作ガイドへ本番開始の手順を追加した。
- Roadmapの古い完了状態を最新コードへ合わせた。

## 3. 安全性

- 自動確認がすべて成功しても、人間確認前は「確認待ち」と表示する。
- Secretの値、DB接続情報、利用者データを画面へ表示しない。
- 外部Dashboard、GitHub Actions、Migration、送信、退会処理を画面表示だけで実行しない。
- Platform Admin以外は既存の404境界で管理画面へ入れない。

## 4. 人間確認として残す項目

- backup復元練習
- 最新mainのMigration／Health Smoke記録
- 本番LINE・メールLogin／Logout
- スマートフォンで初回投稿完了までのsmoke
- 退会dry-run
- LINE Go/No-Go
- 対象commitと責任者の最終承認
