# 深層パーソナル占い Phase 3 PR-4

基点は `main` の `90c818f2`（#1556）。productionブランチは調査時点で `28026d86`。

## 操作と体験

|      | 通常タロット                                       | 深層パーソナル占い                                                                                                           |
| ---- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 開始 | テーマを選び、今日のカードを引く                   | 相談を整理する入口からテーマを選ぶ。質問は任意で、途中で鑑定へ進める                                                         |
| 結果 | カードの標準解釈、または既存のAI鑑定と今日の提案   | 本人確認済みの相談とカードの解釈を示し、状況に合う見方・選択肢・一歩を提案                                                   |
| 次回 | 同意済みのプロフィール、既存の振り返り・評価を活用 | 「次回のために選んで保存」で許可した項目を使う。次の日以降の相談開始時に確認でき、状況が変わった場合は今回の相談に追記できる |
| 設定 | プロフィール・通知を本人が変更                     | 「保存した相談内容」で確認・訂正・削除できる。プロフィール同意の撤回でも消去する                                             |

両方ともServiceの1日1回の抽選と同じカードのフォールバックを使う。運営者は既存の案内役設定で深層鑑定を有効にできる。既定はOFF。

## 設計判断と変更箇所

- 保存済みの相談はPR-2の `FortuneParticipant` の本人選択・版・保存期限を再利用する。前日以前の有効な項目だけを深層鑑定に渡し、同一項目の今回の回答を優先する。生成前後と保存時に同意・版・期限を検証する。過去の深層鑑定の本文や行動提案は、次回生成用の履歴から外す。関連する処理は `fortune-understanding.ts`、`fortune-generation-repository.ts`、OpenAI Providerにある。
- `fortune_intake_sessions` は参加者・日本時間の日付ごとに開始1件、表示した質問数、確認して進んだかスキップしたかのみを保持する。既存の質問予約は当日限り。集計用記録は最大30日、サービスの保存期限が短ければその期間内で消去する。相談・回答・カード・AI原文はこの表に保存しない。計測失敗時にも鑑定は利用できる。
- 運用品質画面の「深層鑑定の利用状況」に、開始、完了、スキップ、翌日以降の未完了、平均表示質問数、深層鑑定件数、別日再訪、個別化評価を表示する。当日の進行中セッションは完了率・スキップ率の分母から除く。既存のService専用BunshinのAI台帳をPrompt Versionで分け、ヒアリングと深層鑑定の月次の成否、トークン、概算原価を表示する。

## 検証と運用

隔離PostgreSQLでマイグレーションとDBの統合テストを実行する。既存の隔離E2Eランナーは実際のローカルGoTrueセッションを使い、スマートフォン幅の操作を確認する。深層鑑定フローではネットワークを遮断し、合成AI応答で本人保存、翌日参照、同意撤回、利用集計、使用量と原価記録を検証する。手順は [隔離環境での占い検証](FORTUNE_ISOLATED_AUTH_E2E.md) を参照。

実AIでの質問・鑑定の文章品質と原価、本番設定と反映、実LINEの配信は別途承認のうえ確認する。
