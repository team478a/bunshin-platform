## 3. 主要な設計判断

- User IDをAPI入力として受け取らず、verified sessionから確定する。
- ACTIVEなWorkspace Membershipがない場合は情報を返さない。
- PointAccountが未作成の本人には0 WPを表示し、最初の付与を待てるようにする。
- 失効予定は30日以内の付与から既消費分を除いて表示する。
- Rule Key、Group ID、Campaign IDなどの内部情報は利用者画面へ表示しない。
- ポイント取得に失敗しても、既存機能へ戻れる縮退画面を表示する。
