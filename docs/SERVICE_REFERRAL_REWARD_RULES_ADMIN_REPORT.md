# 紹介特典ルール管理 実装報告

## 目的

サービス管理者が、自サービス内の紹介特典を管理画面から安全に設定できるようにする。

## 提供する設定

- 初期設定完了時の特典
- 最初の投稿報告時の特典
- 受取人（紹介した人 / 紹介された人）
- 画像作成回数
- 有効期限
- 受取人1人あたりの月間付与上限
- 有効・停止

## データ保護

- 設定は `workspaceId + groupId` で必ず分離する。
- サービス所有者・サービス管理者だけが設定できる。
- 変更時は既存ルールを上書きせず、新しい版を保存する。以前の版は `SUPERSEDED` にする。
- 過去に付与済みのクレジットや、その付与根拠となるルール版は変更しない。

## 対象外

- クレジット残高の利用者向け表示
- 有効期限を過ぎたクレジットの失効処理
- 画像生成時のクレジット消費
- 現金、換金、多段紹介、不正判定
