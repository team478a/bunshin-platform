# 運営者向けポイント・バッジ訂正 実装報告

## 目的

無料運用中に誤って付与したポイントやサービス独自バッジを、運営者が履歴を失わず訂正できるようにする。

## 実装内容

- サービス管理画面から参加者と減算数、理由を指定してポイントを訂正する。
- ポイント残高を超える減算と回収処理中の減算を拒否する。
- 訂正は`REVERSAL`取引として追記し、元の付与履歴を変更しない。
- 訂正分を未使用の付与取引へ紐づけ、期限表示と台帳残高を一致させる。
- サービス独自バッジの有効な付与を、理由付きで`REVOKED`へ変更する。
- 取消前の未送信・再送待ちLINE通知を停止する。
- 取消済みバッジを運営者の集計から除外し、同じバッジの再付与を可能にする。

## 境界と監査

- ポイント操作は、操作対象のサービスを管理できる利用者だけが実行できる。
- 対象者が同じWorkspace・Serviceの有効な参加者であることを再確認する。
- バッジ取消は、対象サービスの`SERVICE_OWNER`または`SERVICE_ADMIN`に限定する。
- ポイント訂正は`ServiceConfigurationAudit`、バッジ取消は`BadgeAdminAuditLog`へ、理由と実行者を保存する。
- 物理削除は行わない。
