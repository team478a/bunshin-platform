# 日常運用の管理機能強化

## 今回のゴール

日常的な管理者変更とログイン問い合わせ対応で、サーバーやDBを直接操作しない状態にする。

## 追加した機能

- 管理者一覧と状態確認
- 登録済みユーザーをメールアドレスで管理者へ追加
- 最高管理者、運用担当者、サポート担当者の役割変更
- 管理権限の停止と再開
- 変更理由を必須にした追記型監査履歴
- 最後の最高管理者と操作中の本人を誤って停止しない保護
- ログインメールの送信上限と一般送信エラーの画面案内

## 管理画面へ置かない情報

- DB接続情報
- Supabase Service Role Key
- API Key、Channel Secret、署名親鍵の平文
- Vercel認証情報

## 次の運用強化候補

1. ユーザー利用停止・再開と理由付き監査
2. 問い合わせ対応メモと担当者管理
3. 障害・配信失敗・費用超過をまとめた通知センター
4. CSV出力と定期運用レポート

これらは今回の権限管理と分離し、権限境界と保持期間を個別確認して追加する。
