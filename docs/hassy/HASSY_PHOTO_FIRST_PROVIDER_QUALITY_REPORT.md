## 1. 結論

合成写真と架空企業だけを使い、実OpenAI Providerによる代表4 Goal（認知・採用・来店予約・問い合わせ）の差分検証を完了した。各実行では写真解析、本文生成、品質判定をGoalごとに各1回、合計6回に制限し、再試行は行っていない。

認知では「施術前の確認を大切にする美容室」という店舗特徴の想起を中心に、保存を促すCTAが生成された。採用ではテーマ自体が「施術前の確認を大切にする職場」へ移り、未経験者・ブランク復帰者向けの働き方、段取り、見学相談を中心とするCTAが生成された。末尾のCTAだけを差し替えた結果ではなく、テーマ、切り口、推奨理由、本文、写真の使い方がGoalに応じて変化した。

来店予約では、初回来店の流れと確認項目を示して空き状況確認へ誘導した。問い合わせでは、相談前の不安をFAQで解消し、LINEで質問する導線へ誘導した。両者もテーマ、読者価値、本文、CTAが分かれている。

品質判定は認知92点、採用88点、来店予約92点、問い合わせ92点で、いずれも`PASS`だった。この結果は当該1写真・1架空業種・4 Goalの代表サンプルに限る。全Goal、全業種、本番運用の品質を証明するものではない。

### Goal差分

| 比較項目     | 認知（`BRAND_AWARENESS`）                      | 採用（`RECRUIT`）                        |
| ------------ | ---------------------------------------------- | ---------------------------------------- |
| テーマ       | 施術前の確認を大切にする美容室という特徴の想起 | 施術前の確認を大切にする職場と仕事の実像 |
| 切り口       | 相談しやすさを作る店舗の工夫                   | 確認・共有・施術という働き方と段取り     |
| 対象         | 初来店に不安を持つ顧客                         | 未経験者・ブランク復帰者を含む応募候補者 |

採用結果は「店舗紹介文の末尾にスタッフ募集中を追加しただけ」ではなく、職場、仕事の進め方、教育上の安心、見学時の確認事項へ投稿戦略そのものが変化している。

| 比較項目     | 来店・予約（`VISIT_RESERVATION`）      | 問い合わせ（`INQUIRY`）            |
| ------------ | -------------------------------------- | ---------------------------------- |
| テーマ       | 初回来店の流れと施術前のすり合わせ     | 相談前の不安を減らす施術前FAQ      |
| 切り口       | 来店時に何を確認するかを段階表示       | 問い合わせ前の疑問へ質問形式で回答 |
| 対象         | 予約を検討中で初回来店に不安がある顧客 | 相談内容や伝え方に迷う顧客         |
| 写真の使い方 | 来店の流れを説明するカルーセル導入     | FAQと相談項目を示すチェックリスト  |
| CTA          | プロフィールから空き状況を確認         | LINEで質問を送る                   |

来店予約と問い合わせは近いコンバージョン目的だが、前者は来店意思決定と空き状況確認、後者は相談障壁の解消とLINE質問へ分岐した。

## 4. 判定
