# 本番検証開始ダッシュボード 実装報告

## 目的

直近で追加した週次トレンド調査を、ファイル編集やサーバー操作ではなく管理画面から準備・確認し、100人検証の開始可否へ反映する。

## 追加した確認

- Grok、Exa、Firecrawlのうち、少なくとも1つが本番で使用中である
- 使用中Providerが全体停止されていない
- 接続テストが成功し、未解決の接続エラーがない
- 本番データで調査を1回実行し、出典、候補、有効期限、Missionへの反映、設定原価を人が確認した
- 確認結果を対象commit別の追記型証跡へ保存した

## 最終承認

`TREND_RESEARCH_SMOKE`を追加し、この証跡を含むすべての人間確認が有効でなければ`FINAL_APPROVAL`を記録できない。新しいcommitを配備した場合、以前の確認は自動で引き継がれない。

## 権限と安全性

- 証跡の記録・取消は既存どおりProductionのSUPER_ADMINだけが行う
- APIキー、検索結果本文、利用者情報は証跡へ保存しない
- 接続確認と実データ確認を同じ扱いにしない
- トレンド調査が失敗しても通常の投稿企画は継続する

## グループ発信との境界

1社先行テストは人格学習G7へ進むための条件であり、一般利用者向けFREE検証の開始を妨げる条件にはしない。先行テスト準備とKPIは既存の参加募集管理画面で確認する。
