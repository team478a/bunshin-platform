# サービス別設定マニュアル

千ノ国メディア、副業アカウント、ワタシワークス公式は、同じ基盤を使いながら配信目的を分けて運営します。

## 基本方針

| サービス           | 対象                   | 基本の配信 | 基本の内容     | 基本の形式 |
| ------------------ | ---------------------- | ---------- | -------------- | ---------- |
| 千ノ国メディア     | 情報発信を続けたい個人 | 投稿予定日 | 完成した投稿案 | 文章       |
| 副業アカウント     | 副業を始めたい個人     | 投稿予定日 | 完成した投稿案 | 文章       |
| ワタシワークス公式 | 企業、店舗、個人事業主 | 毎日       | 発信アイデア   | 文章       |

## 千ノ国メディア

参加者がSNS、発信相手、紹介する活動、目標、使える時間を登録します。投稿パートナーが週間予定を作り、予定がある日の朝に投稿案を準備します。

- 毎日のアイデア配信は停止する。
- 投稿予定に基づく通常配信を使う。
- 内容は「そのまま使える投稿案」にする。
- 標準メディアは文章にする。
- 紹介元の記録とトレンド調査を利用できる。

## 副業アカウント

個人の副業や商品紹介を支援します。基本構成は千ノ国メディアと同じで、商品情報、必須表記、避ける表現、参加者専用URLを運営者が用意します。

- 誰でも参加できる登録方式を基本にする。
- メールとLINEを利用できるようにする。
- 投稿予定に基づく通常配信を使う。
- 紹介機能を有効にする。
- 商品投稿は必要に応じてコピー前の承認を設定する。

## ワタシワークス公式

企業や店舗が発信を始めるきっかけとして、業種と事業内容に合うアイデアを無料で届けます。

- LINEを主な登録・通知方法にする。
- 事業プロフィールを有効にする。
- 毎日のアイデア配信を有効にする。
- 標準時刻を08:00にする。
- 内容は「発信アイデア」、形式は文章にする。
- 業種、事業名、地域、商品・サービス、目的、対象顧客を登録してもらう。

完成投稿、画像、動画を提供するプランでは、公式プログラムまたは参加者設定で支援内容を変更し、生成機能、月間利用枠、本人同意を確認します。

## 本番開始前の共通確認

1. サービス名、運営会社、問い合わせ先、ロゴを確認する。
2. 利用規約とプライバシーポリシーを公開する。
3. LINE設定を接続確認し、使用中にする。
4. 標準リッチメニューを公開する。
5. 公式資料、FAQ、商品情報、禁止表現を登録する。
6. 運営担当者へ必要最小限の権限を付与する。
7. テスト参加者1名で、登録、初回設定、投稿案、LINE通知、投稿完了を確認する。
8. 画像・動画を使う場合は、利用枠、保存先、配信結果を実機で確認する。
