# 本人素材を集めるDaily Action 実装報告

## 実装した内容

- サービス利用者の投稿パートナー画面へ、写真、お客様の質問、30秒メモ、コメント返信、過去投稿の改善案、休む理由の6種類を追加した。
- 文章は本人所有のBunshin Memoryとして保存し、次回の通常投稿案と別案の企画・本文生成へ渡す。
- 写真は本人、Workspace、Service、Bunshinを含む非公開パスへ保存する。保存時に画像として検証し、向き補正とメタデータ除去を行ったJPEGへ変換する。
- 素材が少ないときに答えやすい追加質問を画面へ表示する。
- 保存履歴の確認、写真の短期URL表示、削除を追加した。
- アカウント削除時のメディア削除対象へDaily Action写真を追加した。

## 分離と生成の規則

- APIはURLや本文からWorkspace、Service、利用者IDを受け取らず、公開Service設定とログイン利用者から確定する。
- Bunshinの所有者とService参加状態が一致しない場合は一覧、作成、写真表示、削除を許可しない。
- Service管理者が利用者本人ではない場合、管理者権限だけで本人Memoryを生成へ渡さない。
- 本人素材は投稿の参考事実として扱い、既存の「本人の体験を捏造しない」品質規則を維持する。

## 無料運用での音声入力

音声ファイルの文字起こしAPIは使わず、iPhone標準キーボードのマイク入力で30秒ほど話し、文章として保存する。追加のAI原価を発生させず、投稿生成がそのまま読める素材にする。

## 本番確認

Migration適用後、iPhoneのLINE内ブラウザで6種類の保存、写真撮影・選択、写真表示、削除を確認する。翌回の投稿案に本人素材が反映され、別利用者の素材が混ざらないことを確認する。
