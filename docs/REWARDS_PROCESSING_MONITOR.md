# ポイント・バッジ自動反映の運用監視

無料運用中にポイントやバッジの反映停止へ気づけるよう、システム管理者の「ポイント・バッジの自動反映」画面を追加する。修復操作を扱う「ポイント残高の確認」と分離し、運用担当者も閲覧できるようにする。

## 表示する内容

- 過去24時間に処理を完了したポイント行動とバッジ行動の件数
- 現在失敗して自動再試行を待っている処理
- 10分以上処理中のままになっている処理
- ポイント付与を一括停止しているサービス

問題のある処理は古い順に表示し、行動、利用者、団体、状態、最終処理時刻を確認できる。投稿本文、プロンプト、メールアドレス、秘密値は表示しない。

同じ異常は管理者の「運用通知」にも表示する。処理失敗と一括停止は別の通知にし、一時障害の自動再試行と、運営者が意図して行う停止を混同しない。
