# ポイント・バッジ4週間試験の開始確認

サービス管理画面の「ポイントとバッジ」に、試験開始前の確認欄を表示する。

## 開始条件

- サービスでポイントとバッジの試験利用が許可されている
- 開始日と、開始日から28日以上後の終了日が設定されている
- 現在利用できる試験利用者が1〜30人いる
- ポイント付与が一括停止されていない
- ポイント付与条件が1種類以上有効になっている

不足している項目には「この設定を直す」を表示する。サービスの利用許可と期間はシステム管理者の設定画面、参加者は参加者管理画面、ポイント付与と付与条件は同じページ内の該当欄へ案内する。

5項目がそろった場合は「準備完了です。試験を開始できます。」と表示する。設定済みの試験期間が終了している場合は、開始判定の代わりに試験結果とCSV保存へ案内する。
