# サービス紹介用投稿文 実装レポート

## 目的

サービス参加者が、自分専用のサービス紹介URLをSNSで安全に案内できるようにする。千ノ国メディア固有の実装にはせず、後続の副業サービスでも使えるサービス共通機能とする。

## 実装内容

- 参加者向け`/s/{serviceSlug}/activity`に「紹介用の投稿文」を追加した。
- Instagram、X、Threadsを選択し、媒体の文字数上限内で投稿文を作成できる。
- 投稿文にはサービス名、公開説明、本人の紹介URL、`#PR`を含める。
- 紹介URLへ`source=member_share`と投稿先だけを付与し、既存の匿名クリック計測へ接続した。
- 投稿前に全文を表示し、参加者が確認してからコピーする。SNSへの自動投稿は行わない。

## 境界と安全性

- 商品・代理店成果用の`ExternalTrackingLink`および`{{referral_url}}`とは分離した。
- URLはHTTPSかつ`/r/{code}`形式に限定し、認証情報やfragmentを含むURLを拒否する。
- 計測情報へ氏名、メールアドレス、LINE IDなどの個人情報を含めない。
- 通常のDaily Missionへ紹介URLを自動挿入しない。参加者の明示操作が必要である。
- AI Providerを使わないため、この機能単体ではAI利用料や生成待ち時間を発生させない。

## 検証

- Application単体テスト: PR表記、媒体別上限、計測パラメータ、URL拒否
- Web境界テスト: 明示操作、手動投稿、商品URL・AI生成との分離
- Application/Webの型検査とlint
- Next.js production build

- 参加者プロフィールを安全に反映した紹介文候補
