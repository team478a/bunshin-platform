# AIパーソナル占い Phase 2 PR-3

- PR-2統合後の `main`（`56551bae`）から実装した。対応する公開・AI・個別化が有効で、同意が有効な本人は「今日の占い」または個別の鑑定結果の下から、候補または自由入力で質問できる。元の鑑定のカードと正逆は固定する。
- 運営者は「ヒアリングとAI案内役の設定」で、同じ鑑定への追加質問を停止、1回、2回から選ぶ。旧設定の既定は2回。読み直しや同じ送信IDの再送で新規AI実行は発生しない。AI呼び出しに失敗した送信も回数に含める。
- 追加質問は `fortune_reading_follow_ups` で元の鑑定に紐づける。DBで順番を一意にし、本人のプロフィールと鑑定をロックして同時送信を制御する。鑑定の期限切れに連動して削除し、同意撤回・退会・鑑定削除・同意の期限切れでは質問と回答を消去する。元の鑑定を保持する場合は利用済み回数だけが残る。
- 既存のAI Provider、組織・Service利用枠、原価計上、構造化出力と安全性検証を再利用する。追加質問ごとのキーとプロンプト版で識別し、既存の占い原価に含める。AIへの入力は対象の鑑定と同じ鑑定内の会話に限る。
- マイグレーション `20261121010000_fortune_reading_follow_ups` は本番反映前に別の手順で適用する。実AIの回答品質と実機E2Eは隔離環境で確認する。PR-4は提案・評価・分析と先行運用を扱う。
