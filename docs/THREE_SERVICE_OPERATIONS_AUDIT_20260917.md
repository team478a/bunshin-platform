## 3. 共通基盤

### 正常

- `GET /api/health/ready` は200で、production / configuration / authentication / database / databaseSchemaがすべて正常。
- 最新main `3408ae3a` のCIは成功。
- サービス別の利用規約とプライバシーポリシーは200で表示できる。
- 千ノ国メディアとワタシワークス公式の公開入口・ヘルプは200。
- 未認証の利用者は、戻り先を保持してログインへ移動する。
- LINE登録はサービス境界を保持し、同じ利用者の確認済みLINE接続を安全に再利用する実装がある。

### 残る共通課題

1. `/account` をサービス指定なしで直接開くと、共通の `/terms` と `/privacy` が表示される。両ページは現在も「準備中」。サービスのリッチメニューは `?service=...` を付けるため通常導線ではサービス別文書になるが、グローバル画面から直接開いた場合の案内は未完成。
2. 運営画面でLINE由来の表示名を取得できない利用者はUUID表示になる。権限管理はできるが、問い合わせ対応時に誰か判別しにくい。事業名・活動名または運営者用表示名を併記する改善が必要。
3. 実際のiPhone・LINEアプリでの受信、コピー、投稿完了は自動テストでは確認できない。各サービスで最低1件の本番スモークテストが必要。

## 4. 千ノ国メディア

### 実装済み・本番確認済み

- 公開入口、ヘルプ、初心者向けWebマニュアル、利用規約、プライバシーポリシー
- 専用LINEは「使用中」「接続確認済み」。標準リッチメニューも公開済み。
- 利用中17人、運営担当2人。一般参加者15人がポイント・バッジ試験を利用可能。
- 4週間のポイント試験は2026年9月12日から10月10日まで設定済みで、5つの開始条件はすべて準備済み。
- 3種類のポイント付与条件、誤付与回収、返却、交換履歴、CSV出力、バッジ管理を利用可能。
- 画像生成は停止され、5枚で完結する画像用プロンプトをコピーしてChatGPT等へ送る導線になっている。
- 投稿パートナー画面で、投稿案、画像用プロンプト、投稿文、CapCut利用案内を確認できた。
- 公開法務文書には和愛株式会社、所在地、代表者、問い合わせ先が掲載されている。

### 本番で確認した注意事項

| 優先度 | 状態                                             | 影響                                                                                                                   |
| ------ | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 高     | 直近7日間のLINE送信0件、送信失敗1件              | 現在の専用LINE設定で正常に届く証拠がまだない                                                                           |
| 高     | 直近7日間の投稿完了0件                           | ポイント自動付与を含む利用者の一連の操作が未確認                                                                       |
| 中     | AI成功65回、失敗27回                             | 全停止ではないが失敗率が高い。新しい投稿案1件の成功確認が必要                                                          |
| 低     | 動画失敗3件                                      | 現在のプロンプト中心運用には影響しない。動画を再開するときに処理する                                                   |
| 低     | 開始準備11/14                                    | 未完了3件は商品情報、商品キャンペーン、参加者別URL。投稿支援とポイント試験には不要だが、商品紹介運用を始める場合は必須 |
| 低     | 15人中、投稿・3日継続・ポイント利用はいずれも0人 | 機能不良とは断定できないが、利用開始後の効果はまだ測れない                                                             |

### 開始判断

投稿支援とポイントの限定運用は開始できる。ただし、次の本番確認を同日に行い、失敗した場合は新規案内を止める。

1. 現在登録済みの参加者1人で、投稿予定日のLINE通知を受信する。
2. リッチメニューから投稿案を開く。
3. 画像用プロンプトと投稿文をiPhoneでコピーする。
4. 「投稿しました」を押す。
5. 10WPが付与され、運営画面の投稿完了とポイント集計が1件になることを確認する。

現在の15人は再登録不要。既存の有効なService会員状態をそのまま使える。

## 5. 占い

### 実装済み

- `FORTUNE_DAILY_GUIDANCE` パッケージと版管理
- 運営団体ごとの提供許可、100人上限、導入・更新監査
- 標準解釈468件、運営者所有の占い担当、非公開初期値
- ロゴ・問い合わせ先、利用規約、プライバシー、公式LINEを含む5つの公開ゲート
- 18歳以上の確認、1日1回、恋愛・仕事・人間関係のテーマ、正逆位置を含むカード抽選
- AI個別化の任意利用と、失敗時の標準文への切替
- 結果詳細、初回閲覧記録、90日履歴、選択式評価
- 希望者だけへの週次LINE通知と送信直前の同意再確認
- 占いServiceだけの退会と再参加
- 期限切れ結果の日次削除
- 利用者マニュアル、運営者マニュアル、運用品質・継続ファネル・AI原価の集計

### 運用開始を止める項目

1. 現在の運営者アカウントに占いServiceの管理入口がない。
2. バージョン管理された本番初期データにも、具体的な占いServiceの作成は含まれていない。
3. 本番で「公開中」「公開準備5/5」「参加者1人以上」を確認できていない。
4. テスト利用者による年齢確認、今日の占い、結果閲覧、履歴の一連の実績を確認できていない。
5. 占い固有の利用規約・プライバシー・問い合わせ先・ブランドが未確認。

### 開始判断

コード上の主要機能は実装済みだが、商品として導入されたServiceが確認できないため、実運用は開始できない。次の順で準備する。

1. 占いパッケージ利用可能な運営団体を決める。
2. 占いテンプレートで非公開Serviceを作る。
3. パッケージを導入し、標準解釈468件を確認する。
4. ブランド、問い合わせ先、利用規約、プライバシー、公式LINEを設定する。
5. 5/5になってから公開する。
6. 運営者とは別の1アカウントで、登録、18歳以上確認、占い作成、結果閲覧、履歴、評価、通知停止、Service退会まで確認する。

AI個別化と週次LINEは、標準文による基本動作が安定してから有効化する。

## 6. ワタシワークス公式

### 実装済み・本番確認済み

- 公開LINE登録
- 企業情報の4段階初期設定
- 1日1件の完成投稿文をLINEで届ける設定
- 初期運用で画像・動画・商品配布・紹介報酬を使わない制限
- 投稿案の確認、コピー、採用・見送り、投稿完了、成果の自己申告
- 専用LINEは使用中・接続確認済み。標準リッチメニューも公開済み。
- サービス別利用規約とプライバシーポリシー
- 7日・30日継続、投稿、成果、感想を個人本文なしで集計する運営画面

### 運用開始を止める項目

| 優先度 | 状態                              | 影響                                           |
| ------ | --------------------------------- | ---------------------------------------------- |
| 高     | 一般参加者0人                     | 登録から利用までの本番確認ができない           |
| 高     | LINE送信0件                       | 登録完了通知と毎日の文章配信の成功実績がない   |
| 高     | 投稿案0件、コピー0回、投稿完了0件 | 主要価値を本番で確認できない                   |
| 中     | 開始準備9/10                      | 未完了は一般参加者だけ。設定機能の不足ではない |

### 開始判断

一般公開はまだ開始しない。運営者とは別のテスト用LINEアカウント1件で次を完了すれば、3〜5社・7日間の限定テストへ進める。

1. 公開登録URLからLINE登録する。
2. 企業情報と希望受信時刻を設定する。
3. 登録完了メッセージを受信する。
4. 次の配信時刻に完成投稿文を受信する。
5. リッチメニューから投稿文を開き、コピー、投稿完了を記録する。
6. 運営画面でLINE送信、投稿案、コピー、投稿完了が各1件以上になることを確認する。

## 7. 不具合・不足の優先順位

### P0: 運用開始前に必須

1. 千ノ国メディアの専用LINEで、最新設定による実受信を1件成功させる。
2. 千ノ国メディアで投稿完了と10WP付与を1件成功させる。
3. ワタシワークス公式でテスト参加者1人の全導線を成功させる。
4. 占いServiceを実際に導入し、5つの公開条件をそろえる。

### P1: 限定運用中に対応

1. 千ノ国メディアのAI失敗27件を原因別に確認し、最新の失敗が続く場合は投稿案配信を止める。
2. 運営画面の参加者UUID表示へ、事業名・活動名または運営用表示名を併記する。
3. 占いを別アカウントで端末確認し、週次LINEは基本利用が安定した後に試す。

### P2: 拡張時に対応

1. 千ノ国メディアで商品紹介を行う場合、商品情報、キャンペーン、参加者別URLを準備する。
2. サービス未指定の共通利用規約・プライバシーページを正式公開する。
3. 千ノ国メディアの停止中動画3件を、動画運用を再開する前に整理する。
