# AI・検索サービス設定 管理画面実装報告

## 実装範囲

- 管理画面 `/admin/ai`
- 管理API `/api/admin/ai-provider-configurations`
- OpenAI・Exa・Firecrawlの環境別下書き作成と履歴表示
- OpenAIモデル、日次予算、月次予算、任意のAPIキー登録
- `ENCRYPTION_KEY` から用途別に導出したAES-GCM鍵によるAPIキー暗号化
- APIキーの再表示禁止と末尾マスク表示
- 同一生成元、認証、管理者権限、入力値検証

## 安全な初期状態

新しい設定は必ず下書きかつ全体停止状態で保存する。管理画面から接続確認や有効化はまだ行えないため、APIキーが誤って外部通信に使われることはない。

## 今後の作業

APIキーの準備後に、Providerごとの接続テスト、接続確認済み設定だけを有効化する操作、使用量に基づく自動停止を追加する。
