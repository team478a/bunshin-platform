# OEM料金表管理 実装報告

## 目的

MAU月額料金をコード変更せず改定できるようにし、確定済み請求を変更せず将来月から新料金を適用する。

## 実装内容

- 料金表のバージョン、適用開始月、段階別金額を保存
- システム管理者だけが全体請求画面から将来料金を登録
- 適用月時点で最新の料金表を月中表示と月次確定に使用
- 3,001 MAU以上は従来どおり個別見積
- 過去月・当月を開始月に指定できない検証
- 段階上限の重複・逆転、負数金額を拒否
- 料金改定後も確定済み`TenantMonthlyUsage`と請求書Snapshotは変更しない

## 運用

料金改定時は翌月以降の月初を適用開始日に指定する。同じ開始月または同じバージョンは登録できない。誤登録した料金表の編集・削除は請求根拠の改変につながるため提供しない。

## 対象外

- OEM団体ごとの個別単価
- 日割り計算
- 確定済み月への遡及適用
- 消費税率の管理
